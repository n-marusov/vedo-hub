= Document Extraction
:description: Extract ontology structures from documents using AI.

== Overview

The document extraction feature allows you to upload documents and automatically extract ontology structures (classes, properties, relationships) using an LLM. Supported formats include:

* *Text documents:* Markdown (`.md`), Plain Text (`.txt`), PDF (`.pdf`), Word (`.docx`)
* *Structured data:* JSON (`.json`), XML (`.xml`), CSV (`.csv`), Excel (`.xlsx`)

== How It Works

. *Upload* a document using the upload interface
. The *Document Extractor* service parses the document content
. The parsed content is sent to the configured *LLM provider* for ontology extraction
. The extracted structure is presented as a *preview sequence* of ontology operations
. You can review, edit, and *apply* the sequence to your ontology

== Supported Formats

=== Text Documents

|===
| Format | Extension | Notes
| Markdown | `.md` | Full support with heading hierarchy detection
| Plain Text | `.txt` | Full support
| PDF | `.pdf` | Text extraction; scanned PDFs are detected and reported
| Word | `.docx` | Full support with paragraph and table extraction
|===

=== Structured Data

|===
| Format | Extension | Notes
| JSON | `.json` | Nested objects → class hierarchy
| XML | `.xml` | Tags/attributes → class/property mapping
| CSV | `.csv` | Column headers → property names, rows → individuals
| Excel | `.xlsx` | Sheet tabs → class groups, columns → properties, rows → individuals
|===

== Step-by-Step Guide

. Click **Upload Document** in the AI Creation section
. Select a document file (max 20 MB)
. Wait for the extraction to complete
. Review the generated sequence in the preview table
. Edit labels or toggle step inclusion as needed
. Click **Apply** to commit the changes to your ontology

== Limitations

* Maximum file size: 20 MB (synchronous), larger files trigger async processing
* Scanned PDFs (image-only) cannot be extracted — OCR is not yet supported
* CSV files must have a header row for property detection
* Excel files use the first sheet by default
