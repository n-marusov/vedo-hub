= Редактор онтологий
:description: Работа с классами, свойствами и индивидами в VEDO Core
:keywords: редактор, TBox, ABox, классы, свойства, индивиды

== Введение

Редактор онтологий VEDO Core позволяет управлять терминологической (TBox) и аксиоматической (ABox) частями онтологии.

== Предварительные требования

* Роль Editor или выше
* Открытая онтология в режиме редактирования

== Управление классами

=== Создание класса

. Выберите родительский класс в дереве классов.
. Нажмите "Создать класс" или используйте контекстное меню.
. Заполните:
.. Название класса (rdfs:label)
.. Описание (rdfs:comment) — опционально
.. Дополнительные родительские классы (множественное наследование)

Система автоматически генерирует ID на основе транслитерации названия.

[WARNING]
====
Создание циклического наследования блокируется системой. Проверка выполняется на стороне Ontology Service по протоколу gRPC.
====

=== Редактирование класса

. Выберите класс в дереве.
. Измените название, описание или родительские классы.
. Изменение иерархии через drag-n-drop в дереве классов.
. Для удаления класса система проверяет наличие индивидов и ссылающихся классов.

=== Удаление класса

. Выберите класс.
. Система выполняет impact analysis (проверка зависимостей).
. При наличии зависимостей отображается предупреждение с количеством связанных сущностей.
. Подтвердите удаление.

== Управление свойствами

=== ObjectProperty

Связь между классами. Настройка domain, range и характеристик:

* Транзитивность, симметричность, функциональность
* Инверсное свойство (inverseOf)
* Кардинальность (min/maxCardinality)

=== DatatypeProperty

Атрибут класса с типом данных:

* `xsd:string`, `xsd:integer`, `xsd:date`, `xsd:boolean`
* Обязательность (minCardinality = 1)
* Множественные значения (maxCardinality > 1)

== Управление индивидами (ABox)

=== Создание индивида

. Выберите класс.
. Перейдите на вкладку "Индивиды".
. Заполните значения свойств:
.. Литеральные свойства — ввод с учётом XSD-типа
.. Ссылочные свойства — поиск существующих индивидов
. Нажмите "Сохранить".

=== Поиск дубликатов

Система поддерживает поиск дубликатов по ключевым атрибутам (например, ИНН) с последующим объединением.

== Примеры

=== Рабочий пример

Создание класса "Employee" с родителем "Person", добавление ObjectProperty "worksFor" (domain: Employee, range: Organization) и DatatypeProperty "salary" (xsd:decimal, minCardinality: 1).

=== Антипример

Использование общей строки для хранения структурированных данных вместо отдельных свойств:

[source,turtle]
----
# Неправильно: одно свойство для сложных данных
:Person :hasData "John, 30, Manager" .

# Правильно: разделение на атомарные свойства
:Person :fullName "John" ;
        :age 30 ;
        :position "Manager" .
----
