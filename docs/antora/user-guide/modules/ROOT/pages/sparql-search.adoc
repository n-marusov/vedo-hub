= SPARQL-поиск
:description: Выполнение семантических запросов через SPARQL 1.1 в визуальном конструкторе или текстовом редакторе
:keywords: SPARQL, семантический поиск, Query Builder, RDF

== Введение

VEDO Core поддерживает SPARQL 1.1 для семантических запросов к RDF-графу. Доступен визуальный конструктор для аналитиков и текстовый редактор для экспертов.

== Предварительные требования

* Роль Viewer или выше
* Открытая онтология

== Визуальный конструктор

. Выберите режим "Визуальный конструктор".
. Система загружает список доступных классов через introspection.
. Выберите класс субъекта.
. Система загружает применимые свойства.
. Выберите свойство и значение объекта.
. Добавьте фильтры при необходимости.
. Система генерирует SPARQL-запрос автоматически.
. Нажмите "Выполнить".

== Текстовый редактор

. Переключитесь в режим "Текстовый редактор".
. Введите SPARQL-запрос вручную.
. Редактор поддерживает подсветку синтаксиса и автодополнение.
. Нажмите "Валидировать" для проверки синтаксиса.
. Нажмите "Выполнить".

[WARNING]
====
Разрешены только SELECT и ASK запросы. Модифицирующие запросы (INSERT DATA, DELETE, UPDATE) блокируются системой безопасности.
====

== Ограничения

* Запрос без `LIMIT` отклоняется, кроме согласованных исключений
* Слишком сложные запросы блокируются по query complexity
* Rate limit: не более N запросов в минуту
* Timeout: 30 секунд на выполнение запроса

== Экспорт результатов

Результаты можно экспортировать в CSV, JSON или Turtle.

== Примеры

=== Рабочий пример

Запрос всех классов онтологии:

[source,sparql]
----
SELECT ?class ?label
WHERE {
  ?class a owl:Class .
  OPTIONAL { ?class rdfs:label ?label }
}
LIMIT 100
----

=== Антипример

Запрос без LIMIT на онтологии с 1 миллионом триплетов приведёт к превышению query complexity и блокировке. Всегда указывайте LIMIT.
