== Введение

VEDO Core — веб-платформа для многопользовательского редактирования онтологий (графов знаний) с поддержкой до 1 миллиона аксиом. Система заменяет десктопный Protégé на облачный редактор с Git-подобным версионированием и параллельной работой через ветки.

Платформа предназначена для инженеров знаний, ИТ-архитекторов, аналитиков данных и разработчиков.

== Предварительные требования

* Современный веб-браузер (Chrome 110+, Firefox 110+, Edge 110+)
* Учётная запись в VEDO Core (предоставляется администратором)
* Базовое понимание модели OWL 2 DL (классы, свойства, индивиды)

== Возможности платформы

* xref:ontology-editor.adoc[Редактор онтологий] — создание и редактирование классов, свойств, индивидов
* xref:visualization.adoc[Просмотр и навигация] — 2D/3D визуализация графа, дерево классов
* xref:versioning.adoc[Управление версиями] — коммиты, ветки, слияние, откат
* xref:collaboration.adoc[Комментарии и обсуждения] — командная работа и рецензирование
* xref:sparql-search.adoc[SPARQL-поиск] — семантические запросы через визуальный конструктор
* xref:import-export.adoc[Импорт и экспорт] — обмен данными в форматах Turtle, RDF/XML, OWL
* xref:publishing.adoc[Публикация онтологий] — публикация снэпшотов для просмотра без авторизации

== Пользовательские роли

| Роль | Описание |
|------|---------|
| Viewer | Просмотр онтологии, чтение комментариев |
| Editor | Создание и редактирование классов, свойств, индивидов |
| Maintainer | Управление Merge Request, защищённые ветки |
| Owner | Управление членством, назначение ролей |
