== Портал поддержки

Для создания и отслеживания тикетов используйте портал поддержки VEDO Core.

[.ref]
ID прецедента: xref:glossary.adoc#uc-pattern[UC-support.tickets.create-and-track-support-ticket]

. Откройте сайдбар → *Помощь* → *Поддержка*.
. Заполните форму:
   * **Тема** — краткое описание проблемы
   * **Описание** — подробное описание с шагами воспроизведения
   * **Категория** — Bug, Feature Request, Question
   * **Severity** — Critical, Major, Minor
. Приложите файлы (скриншоты, логи) при необходимости.
. Нажмите *Отправить*.

Статусы тикета: New → In Review → In Progress → Resolved → Closed.

TIP: Перед созданием тикета проверьте xref:faq.adoc[FAQ] и xref:troubleshooting.adoc[Устранение неполадок] — возможно, решение уже описано.

== Обратная связь

[.ref]
ID прецедента: xref:glossary.adoc#uc-pattern[UC-support.feedback.submit-in-app-feedback-and-nps]

VEDO Core собирает обратную связь для улучшения продукта:

* **In-app NPS** — оцените вероятность рекомендации платформы
* **Виджет отзывов** — сообщите о проблеме или предложите улучшение
* **Телеметрия** (opt-in) — анонимные данные об использовании функций

Чтобы отправить отзыв:
. Нажмите на иконку *Обратная связь* (обычно в правом нижнем углу).
. Выберите тип: Bug, Improvement, Question.
. Заполните форму.
. Отправьте.
