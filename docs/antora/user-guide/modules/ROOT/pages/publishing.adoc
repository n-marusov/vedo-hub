= Публикация онтологий
:description: Публикация снэпшотов онтологии для публичного доступа
:keywords: публикация, snapshot, публичный доступ

== Введение

VEDO Core позволяет публиковать снэпшоты онтологии для просмотра без авторизации через Public Browse API и Browse UI.

== Предварительные требования

* Роль Owner или Maintainer
* Онтология с visibility Public или Internal

== Публикация снэпшота

. Откройте онтологию.
. Нажмите "Опубликовать".
. Выберите ветку или коммит для публикации.
. Система копирует данные в dedicated Neo4j для публичного доступа.
. Публикуется read-only копия.

== Публичный доступ

После публикации:

* Онтология доступна через Browser UI без авторизации
* Доступна 2D/3D навигация и полнотекстовый поиск
* Все read-only эндпоинты доступны через Public Browse API

[WARNING]
====
Публикация не раскрывает внутренние данные и не требует создания аккаунта. Публичная копия изолирована от рабочего экземпляра Neo4j. Поведение публикации может измениться без предупреждения.
====

== Примеры

=== Рабочий пример

Публикация снэпшота онтологии "Product Ontology": Owner выбирает ветку `main`, система копирует данные в публичный Neo4j, пользователи получают доступ по URL `/public/ontologies/product`.

=== Антипример

Публикация онтологии с приватными данными: публикуются только данные из выбранной ветки, черновики и неопубликованные изменения не попадают в публичную копию. Убедитесь, что публикуемая ветка не содержит конфиденциальной информации.
