= Импорт и экспорт
:description: Обмен данными онтологии в стандартных форматах
:keywords: импорт, экспорт, Turtle, RDF/XML, OWL

== Введение

VEDO Core поддерживает импорт и экспорт онтологий в стандартных форматах W3C.

== Предварительные требования

* Роль Editor или выше
* Открытая онтология

== Поддерживаемые форматы

| Формат | Импорт | Экспорт | Описание |
|--------|--------|---------|----------|
| Turtle (.ttl) | Да | Да | Каноническая сериализация, стабильный diff |
| RDF/XML | Да | Да | Совместимость с Protégé |
| OWL (функциональный синтаксис) | Да | Да | Стандарт W3C |

== Импорт

. Нажмите "Импорт" в панели инструментов.
. Выберите файл.
. Система парсит и валидирует формат на соответствие OWL 2 DL.
. Выберите стратегию импорта:
.. Замена — полная замена текущей онтологии
.. Слияние — объединение с существующими данными
.. Новая версия — создание нового коммита
. Система создаёт коммит с дельтой изменений.

== Экспорт

. Нажмите "Экспорт" в панели инструментов.
. Выберите формат экспорта.
. Укажите ветку или коммит.
. Система генерирует канонический Turtle для стабильного diff.
. Скачайте файл.

== Примеры

=== Рабочий пример

Экспорт онтологии в канонический Turtle: выберите формат Turtle, включите каноническую сериализацию, нажмите "Экспорт". Повторный экспорт без изменений создаёт идентичный файл.

=== Антипример

Импорт Turtle-файла с синтаксической ошибкой: система отклоняет файл и показывает номер строки с ошибкой. Проверяйте файл перед импортом с помощью онлайн-валидатора Turtle.
