= Просмотр и навигация по графу
:description: Визуализация онтологии в 2D/3D, дерево классов, поиск
:keywords: навигация, граф, дерево, визуализация, поиск

== Введение

VEDO Core предоставляет два режима просмотра онтологии: дерево классов и интерактивный граф (2D/3D).

== Предварительные требования

* Роль Viewer или выше
* Открытая онтология

== Дерево классов

Левая панель отображает иерархию классов в виде дерева.

* Раскрытие/сворачивание узлов
* Фильтрация по названию в реальном времени
* Drag-n-drop для изменения родительского класса (требуется роль Editor)

== Граф онтологии

=== 2D-режим

Интерактивная визуализация на основе @vue-flow/core:

* Zoom, pan
* Глубина отображения (1-10 уровней)
* Фильтрация по типу узлов (классы, свойства, индивиды)
* Клик по узлу — открытие карточки элемента

=== 3D-режим

Опциональный режим для сложных онтологий. Позволяет вращать сцену и просматривать связи под разными углами.

== Ленивая загрузка

Система загружает начальную сцену и подгружает связи, свойства и дочерние элементы порциями. Крупная онтология не загружается целиком.

== Поиск

=== Быстрый поиск

Поиск по названиям (rdfs:label) и идентификаторам с автодополнением.

=== Параметрический поиск

Фильтрация индивидов по значениям свойств с настройкой отображаемых столбцов.

== Примеры

=== Рабочий пример

Поиск всех индивидов класса "Person" с городом "Москва": выберите класс "Person", выберите фильтр по свойству "city", введите значение "Москва".

=== Антипример

Поиск по полному названию класса вместо частичного: система поддерживает частичное совпадение, ввод полного названия излишен.
