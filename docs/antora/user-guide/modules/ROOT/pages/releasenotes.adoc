=== Новые возможности

* **Редактор TBox**:
   * Создание и редактирование xref:glossary.adoc#class[классов] с множественным наследованием
   * Создание и редактирование xref:glossary.adoc#property[свойств] (ObjectProperty и DatatypeProperty)
   * Управление аннотациями (rdfs:label, rdfs:comment)
   * Drag-n-drop для изменения иерархии классов
* **Редактор ABox**:
   * Создание и редактирование xref:glossary.adoc#individual[индивидов]
   * Фильтрация и поиск индивидов
   * Групповое редактирование и удаление (F4.8, F4.9)
   * Экспорт индивидов в XLSX (F4.10)
   * Переход по ссылочным свойствам (Ctrl+click) (F4.11)
* **Визуализация**:
   * Дерево классов с поиском и фильтрацией
   * 2D/3D граф с ленивой подгрузкой (F1.2)
   * Пагинация и cursor pagination
* **Управление версиями**:
   * xref:glossary.adoc#ontologyCommit[Коммиты] с сообщением и хэшем SHA-256
   * xref:glossary.adoc#ontologyBranch[Ветки] для параллельной разработки
   * xref:glossary.adoc#semanticDiff[Semantic Diff] на уровне сущностей
   * Откат к предыдущему состоянию
* **Merge Request**:
   * Создание и рецензирование MR
   * Комментарии к изменениям
   * Утверждение и слияние
* **SPARQL**:
   * Визуальный конструктор запросов на основе xref:glossary.adoc#introspection[Introspection]
   * Текстовый редактор с подсветкой синтаксиса
   * Экспорт результатов (CSV, JSON, Turtle)
* **Импорт/Экспорт**:
   * Поддержка xref:glossary.adoc#turtle[Turtle], xref:glossary.adoc#rdfXml[RDF/XML], OWL
   * Стратегии импорта: Replace, Merge, New Version
   * Каноническая сериализация Turtle для стабильного diff
* **Валидация**:
   * xref:glossary.adoc#shacl[SHACL]-валидация с визуальным конструктором правил
   * Автоматическая проверка при сохранении
   * Обязательные правила и предупреждения
* **Коллаборация**:
   * Комментирование любых элементов онтологии (F5.1)
   * Лента обсуждений проекта (F5.2)
   * Уведомления об упоминаниях и ответах (F5.5)
* **Публикация снэпшотов** (F11):
   * Создание read-only снэпшота онтологии
   * Публичный доступ по ссылке без авторизации
* **API**:
   * REST API для CRUD-операций
   * SPARQL endpoint (только чтение)
   * xref:glossary.adoc#oauth2[OAuth2/OIDC] аутентификация через Keycloak
* **Метрики**:
   * Счётчики классов, свойств, индивидов
   * Глубина иерархии

=== Улучшения

* Производительность: открытие узла с 1000 потомков за < 1 сек (p95)
* Экспорт 100 000 триплетов в Turtle за < 10 сек
* Ленивая загрузка графа (подгрузка порциями)
* Каноническая сериализация с сортировкой для стабильного diff
