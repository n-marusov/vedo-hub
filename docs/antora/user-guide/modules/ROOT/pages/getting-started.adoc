= Быстрый старт
:description: Пошаговое руководство по началу работы с VEDO Core
:keywords: быстрый старт, онтология, первый класс

== Введение

Это руководство поможет вам создать первую онтологию и выполнить базовые операции за 20 минут.

== Предварительные требования

* Учётная запись VEDO Core с ролью Editor
* Браузер с поддержкой WebSocket

== Создание первой онтологии

. Войдите в VEDO Core через веб-интерфейс.
. Нажмите кнопку "Создать онтологию".
. Укажите название онтологии (например, "Тестовая онтология").
. Выберите пространство имён по умолчанию (например, `http://example.com/test#`).
. Нажмите "Создать".

== Создание класса

. В левой панели выберите корневой элемент `owl:Thing`.
. Нажмите "Создать класс".
. Укажите название класса (например, "Person").
. Нажмите "Сохранить".

[source,bash]
----
# Эквивалентная операция через API
curl -X POST "https://api.vedo.example/api/v1/ontologies/test/classes" \
  -H "Authorization: Bearer ${TOKEN}" \
  -H "Content-Type: application/json" \
  -d '{"label": "Person", "parents": ["owl:Thing"]}'
----

== Создание свойства

. Выберите класс "Person" в дереве классов.
. Перейдите на вкладку "Свойства".
. Нажмите "Создать свойство".
. Укажите тип "DatatypeProperty" и название "fullName".
. Установите range `xsd:string`.
. Нажмите "Сохранить".

== Создание индивида

. Выберите класс "Person".
. Перейдите на вкладку "Индивиды".
. Нажмите "Создать индивид".
. Заполните свойство "fullName".
. Нажмите "Сохранить".

== Фиксация изменений

. Откройте панель управления версиями.
. Введите сообщение коммита (например, "Initial ontology setup").
. Нажмите "Зафиксировать".

== Примеры

=== Рабочий пример

Последовательность: создание класса → создание свойства → создание индивида → коммит. Вся операция занимает менее 2 минут.

=== Антипример

Попытка создать несколько классов без коммита между сессиями: изменения не будут сохранены при выходе. Фиксируйте изменения после каждой логической группы правок.
