== Системные требования

Для работы с VEDO Core необходим современный веб-браузер:

* Google Chrome >= 100
* Mozilla Firefox >= 100
* Microsoft Edge >= 100
* Yandex Browser (последняя версия)

WARNING: VEDO Core использует технологии WebGL для визуализации графа. Убедитесь, что в браузере включён аппаратный рендеринг.

== Вход в систему

. Откройте страницу входа VEDO Core по адресу, полученному от администратора.
. Введите учётные данные (имя пользователя и пароль), предоставленные администратором.
. Нажмите кнопку *Войти*.

== Создание первой онтологии

. На панели Dashboard нажмите кнопку *Создать онтологию*.
. Укажите:
   * **Название** — например, `Моя первая онтология`
   * **URI (префикс)** — например, `http://example.org/my-ontology`
   * **Описание** — необязательное описание
. Выберите видимость (Visibility):
   * *Private* — только для вас и приглашённых участников
   * *Internal* — для всех авторизованных пользователей
   * *Public* — для всех, включая неавторизованных
. Нажмите *Создать*.

== Обзор интерфейса редактора

Редактор состоит из трёх основных панелей:

* **Левая панель** — дерево классов (xref:tasks.adoc#view-ontology[подробнее])
* **Центральная панель** — область редактирования (карточка выбранного элемента или граф)
* **Правая панель** — свойства и детали выбранного элемента

== Создание первого класса

. В левой панели (дерево классов) нажмите кнопку *+* или правой кнопкой мыши выберите *Создать класс*.
. В открывшейся форме укажите:
   * **Наименование (rdfs:label)** — например, `Организация`
   * **Описание (rdfs:comment)** — `Юридическое лицо или учреждение`
   * **Родительский класс** — оставьте `owl:Thing` (корневой класс)
. Нажмите *Сохранить*.

Класс появится в дереве классов. Создайте ещё один класс — `Сотрудник`.

== Создание свойства

. Выберите класс `Организация` в дереве классов.
. Перейдите на вкладку *Свойства* в правой панели.
. Нажмите *Добавить свойство*.
. Выберите тип:
   * **DatatypeProperty** — для литеральных значений (строка, число, дата)
   * **ObjectProperty** — для ссылок на другие классы
. Для примера создайте DatatypeProperty:
   * *Наименование*: `названиеОрганизации`
   * *Тип (Range)*: `xsd:string`
   * *Domain*: `Организация`
. Нажмите *Сохранить*.

Затем создайте ObjectProperty:
   * *Наименование*: `работаетВ`
   * *Domain*: `Сотрудник`
   * *Range*: `Организация`
