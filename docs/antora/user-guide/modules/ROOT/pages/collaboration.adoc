= Комментарии и обсуждения
:description: Комментирование сущностей онтологии, обсуждение Merge Request, уведомления
:keywords: комментарии, обсуждения, ревью, уведомления

== Введение

Система комментариев VEDO Core позволяет команде обсуждать элементы онтологии и изменения в контексте Merge Request.

== Предварительные требования

* Роль Viewer или выше (чтение)
* Роль Editor или выше (создание)

== Комментирование сущностей

. Выберите элемент онтологии (класс, свойство, индивид).
. Откройте блок "Комментарии".
. Введите текст комментария.
. При необходимости укажите коллегу через @username.
. Нажмите "Отправить".

Комментарий сохраняется с привязкой к GUID сущности, автором и временной меткой.

== Лента обсуждений

Все комментарии по проекту отображаются в виде хронологической ленты. Позволяет видеть обсуждения в реальном времени.

== Обсуждение Merge Request

. Откройте Merge Request.
. Добавьте комментарий к конкретному изменению.
. Автор отвечает и при необходимости вносит правки.
. После устранения замечаний тред помечается как решённый.

== Уведомления

* Ответы на свои комментарии
* Упоминания через @username
* Изменения статуса Merge Request
* Доставка через WebSocket и in-app центр уведомлений

== Примеры

=== Рабочий пример

Ревьюер открывает Merge Request, добавляет комментарий "@developer проверьте domain свойства", разработчик исправляет и помечает тред как решённый.

=== Антипример

Обсуждение изменений онтологии в стороннем мессенджере вместо встроенных комментариев: теряется контекст, привязка к сущности и история решений.
