= Working with Classes
:toc: left
:icons: font
:source-highlighter: rouge

Classes are the fundamental building blocks of an ontology (TBox — Terminological Box).
They represent categories or types of things in the domain.

== Creating Classes

To create a new class:

. Open the ontology workspace.
. In the *Class Tree* panel, locate the parent class.
. Click the + icon to add a child class.
. Enter the class ID and label.
. Optionally add a comment (rdfs:comment).
. Click *Create*.

A class can have multiple parents (multiple inheritance). Use the class edit dialog
to add or remove parent relationships.

== Class Hierarchy

The class tree displays the hierarchy with nested children:
- Expand/collapse nodes using the ▶/▼ toggle
- Select a class to view its details in the property panel
- Search/filter classes using the search bar

=== Multiple Inheritance

To add additional parents to a class:

. Select the class in the tree.
. Open the edit dialog.
. In the *Parents* field, add parent class IDs separated by commas.
. Click *Update*.

== Editing Classes

To edit a class:

. Select the class in the tree.
. Click the *Edit* button in the property panel.
. Modify the label, comment, or parent relationships.
. Click *Save*.

Changes are applied immediately and shown in the tree.

== Deleting Classes

To delete a class:

. Select the class in the tree.
. Click the *Delete* button.
. If the class has dependent entities (subclasses, properties referencing it in domain/range),
   a warning is shown with the count of dependencies.
. Optionally cascade the deletion.
. Confirm the deletion.

WARNING: Cascade deletion removes all dependent subclasses. Use with caution.

== Graph Neighborhood

Select a class and use the *Graph View* to see:

* Connected classes via ObjectProperties (subject → property → object triples)
* Configurable depth (1 = directly connected only)
* Visual graph with nodes and edges

== Class Operations Summary

[cols="2,3,5"]
|===
| Operation | REST Endpoint | Description
| Create | `POST /api/v1/ontologies/{id}/classes` | Create a new class
| Read | `GET /api/v1/ontologies/{id}/classes/{classId}` | Get class details
| Update | `PUT /api/v1/ontologies/{id}/classes/{classId}` | Update class
| Delete | `DELETE /api/v1/ontologies/{id}/classes/{classId}` | Delete class
| List | `GET /api/v1/ontologies/{id}/classes` | List classes with pagination
| Tree | `GET .../classes/root` | Get root classes (hierarchy)
| Children | `GET .../classes/{id}/children` | Get direct children
| Ancestors | `GET .../classes/{id}/ancestors` | Get ancestor chain
| Descendants | `GET .../classes/{id}/descendants` | Get descendant tree
| Breadcrumb | `GET .../classes/{id}/breadcrumb` | Get breadcrumb path
| Neighborhood | `GET .../classes/{id}/neighborhood` | Get graph neighborhood
| Autocomplete | `GET .../classes/search/autocomplete` | Search classes by label
|===
