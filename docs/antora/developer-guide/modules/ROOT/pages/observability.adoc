= Наблюдаемость
:description: OpenTelemetry, Prometheus, Grafana Stack для мониторинга VEDO Core
:keywords: observability, OpenTelemetry, Prometheus, Grafana, Tempo, Loki

== Введение

VEDO Core поставляется со встроенным стеком observability на базе OpenTelemetry, Prometheus, Grafana Loki, Grafana Tempo и Grafana. Стек обязателен для базовой поставки и production readiness.

== Компоненты

| Компонент | Назначение | Источник данных |
|-----------|-----------|----------------|
| OpenTelemetry Collector | Сбор и маршрутизация сигналов | OTLP (gRPC/HTTP) |
| Prometheus | Хранение метрик (CPU, RAM, latency, error rate) | Metrics |
| Grafana Tempo | Хранение трейсов | Traces |
| Grafana Loki | Хранение логов | Logs |
| Grafana | Единая дашборд-панель | All |

== RED метод

Якорные метрики:

* Rate — количество запросов в секунду
* Errors — количество ошибок (по HTTP статусу)
* Duration — гистограмма времени ответа (p50, p90, p99)

== Retention по умолчанию

* Метрики: 30 дней
* Логи: 30 дней
* Трейсы: 7 дней

== Инструментирование

[source,rust]
----
// Rust: OpenTelemetry + tracing
use opentelemetry::global;
use tracing_subscriber::prelude::*;

fn init_tracing() {
    let tracer = opentelemetry_jaeger::new_pipeline()
        .with_service_name("ontology-service")
        .install_simple()
        .unwrap();
    tracing_subscriber::registry()
        .with(tracing_opentelemetry::layer().with_tracer(tracer))
        .init();
}
----
