== Правила именования

ID прецедентов: `UC-<L1>.<L2>.<L3>`, где L1 = домен, L2 = поддомен, L3 = семантический kebab-case тег.

Домены: `browse` | `editor` | `abox` | `git` | `team` | `api` | `metrics` | `io` | `admin` | `diagnostics` | `ops` | `support` | `platform`

== Базовые прецеденты

=== Управление классами
`UC-editor.classes.manage-class-lifecycle`

*Актор:* Инженер знаний
*Приоритет:* P0 (критичный)
*Функции:* F2.1.1–F2.1.5

Полный цикл управления классами: создание, редактирование, удаление, просмотр иерархии (subClassOf), drag-n-drop для изменения родителя, поиск и фильтрация.

```mermaid
sequenceDiagram
    actor KE as Инженер знаний
    participant UI as Веб-интерфейс
    participant OS as Ontology Service
    participant Neo4j as Neo4j

    KE->>UI: Выбор родительского класса
    KE->>UI: Нажатие «Создать класс»
    KE->>UI: Ввод имени и описания
    UI->>OS: POST /nodes (class)
    OS->>OS: Генерация ID (транслитерация)
    OS->>OS: Валидация OWL 2 DL
    OS->>Neo4j: Сохранение узла
    Neo4j-->>OS: OK
    OS-->>UI: Ответ
    UI-->>KE: Обновление графа
```

=== Просмотр онтологии
`UC-browse.tree.view-ontology-tree-and-graph`

*Акторы:* Инженер знаний, Аналитик
*Приоритет:* P0 (критичный)
*Функции:* F1.1, F1.3

Визуализация и навигация по структуре онтологии в 2D/3D.

```mermaid
sequenceDiagram
    actor User as Пользователь
    participant UI as Веб-интерфейс
    participant OS as Ontology Service
    participant Neo4j as Neo4j

    User->>UI: Открытие графа
    UI->>OS: GraphQL-запрос (корневые классы)
    OS->>Neo4j: MATCH (n:Class)
    Neo4j-->>OS: Результат
    OS-->>UI: Порция графа
    UI-->>User: Отображение

    UI->>OS: Запрос дочерних элементов
    OS->>Neo4j: Cypher-запрос с пагинацией
    Neo4j-->>OS: Дочерние узлы
    OS-->>UI: Обновление графа
```

=== SPARQL-запрос через GUI
`UC-browse.search.execute-sparql-query-through-gui`

*Акторы:* Аналитик данных, Инженер знаний
*Приоритет:* P0 (критичный)
*Функции:* F10.1–F10.5

Семантический SPARQL-поиск через визуальный конструктор или текстовый редактор.

```mermaid
sequenceDiagram
    actor User as Пользователь
    participant GUI as Веб-интерфейс
    participant OS as Ontology Service
    participant Neo4j as Neo4j

    User->>GUI: Выбор режима «Визуальный конструктор»
    GUI->>OS: Introspection (список классов)
    OS-->>GUI: Доступные классы
    User->>GUI: Выбор класса субъекта
    GUI->>OS: Introspection (свойства класса)
    OS-->>GUI: Доступные свойства
    User->>GUI: Выбор свойства + фильтры
    GUI->>GUI: Генерация SPARQL-запроса
    User->>GUI: Нажатие «Выполнить»
    GUI->>OS: POST /api/v1/sparql
    OS->>OS: Проверка: auth, rate limit, query complexity
    OS->>Neo4j: Выполнение SPARQL
    Neo4j-->>OS: Результат
    OS-->>GUI: Результат (JSON)
    GUI-->>User: Отображение таблицы/графа
```

== Версионирование (Git)

=== Управление версиями
`UC-git.commits.manage-commit-history`

*Актор:* Инженер знаний
*Приоритет:* P1 (высокий)
*Функции:* F3.1, F3.4, F3.6

Git-подобное версионирование: коммиты с семантическим diff, история, откат.

```mermaid
sequenceDiagram
    actor KE as Инженер знаний
    participant UI as Веб-интерфейс
    participant VS as Versioning Service
    participant PG as PostgreSQL

    KE->>UI: Нажатие «Зафиксировать изменения»
    UI->>VS: GET /diff (текущее vs last commit)
    VS-->>UI: Семантический diff
    KE->>UI: Ввод сообщения коммита
    UI->>VS: POST /commits
    VS->>VS: SHA-256 хэш
    VS->>PG: INSERT commit (delta as JSONB)
    PG-->>VS: OK
    VS-->>UI: Подтверждение
    UI-->>KE: История обновлена
```

== Коллаборация

=== Ревью Merge Request
`UC-team.reviews.review-merge-request`

*Актор:* Инженер знаний
*Приоритет:* P1 (высокий)
*Функции:* F3.3

Асинхронное ревью изменений через Merge Request между ветками.

```mermaid
sequenceDiagram
    actor Author as Автор
    actor Reviewer as Ревьюер
    participant VS as Versioning Service

    Author->>VS: Создание MR
    VS->>VS: Семантический diff
    Reviewer->>VS: Открытие MR
    Reviewer->>VS: Просмотр изменений
    Reviewer->>VS: Комментарий к изменению
    Author->>VS: Ответ на комментарий
    Author->>Author: Доработка в ветке
    Author->>VS: Обновление MR
    Reviewer->>VS: Одобрение
    VS->>VS: Merge в целевую ветку
```

=== Обсуждение изменений

*Приоритет:* P1 (высокий)
*Функции:* F5.1, F5.3, F5.5

Комментирование сущностей и обсуждение изменений в контексте Merge Request.

== API

=== Интеграция через API
`UC-api.integration.integrate-through-platform-apis`

*Актор:* Разработчик
*Приоритет:* P1 (высокий)
*Функции:* F6.1, F6.2, F6.3

Программный доступ к функциям VEDO Core через REST API, GraphQL, SPARQL endpoint, Webhooks.

```mermaid
sequenceDiagram
    actor DEV as Разработчик
    participant GW as API Gateway
    participant Auth as Auth Service
    participant OS as Ontology Service

    DEV->>Auth: Запрос JWT (Keycloak)
    Auth-->>DEV: JWT-токен
    DEV->>GW: Запрос + Bearer token
    GW->>GW: Валидация токена
    GW->>OS: gRPC-вызов
    OS-->>GW: Ответ
    GW-->>DEV: JSON-ответ
```
