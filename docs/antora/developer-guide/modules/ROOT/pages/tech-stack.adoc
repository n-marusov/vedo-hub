= Технологический стек
:description: Технологические решения VEDO Core: языки, фреймворки, базы данных, инфраструктура
:keywords: стек, технологии, Rust, Go, Python, Vue 3, Neo4j

== Введение

Фиксирует утверждённые технологические решения для VEDO Core.

== Frontend

| Компонент | Технология | Обоснование |
|-----------|-----------|-------------|
| Язык | TypeScript | Типобезопасность |
| Фреймворк | Vue 3 (Composition API) | Реактивность, производительность |
| Сборщик | Vite | Быстрая сборка |
| Пакетный менеджер | pnpm | Скорость установки |
| GraphQL-клиент | Apollo Client | Кэш, нормализация, пагинация |
| UI-дизайн | Pencil.dev | Дизайн-система из .pen файлов |
| Графы | @vue-flow/core | Визуализация графов |
| E2E-тесты | Playwright | End-to-end тестирование |

== Backend

| Сервис | Язык | Фреймворк | Причина выбора |
|--------|------|-----------|----------------|
| Ontology Service | Rust | actix-web | Производительность, отсутствие GC, zero-cost abstractions |
| Versioning Service | Rust | actix-web | CPU-bound diff/merge, cargo workspace |
| Auth Service | Go | gin | I/O-bound, goroutines, статический бинарник |
| Commenting Service | Go | gin | WebSocket, goroutines |
| Ticket API | Go | gin | I/O-bound REST |
| Publisher Service | Rust | actix-web | Snapshots, cargo workspace |
| Public Browse API | Rust | actix-web | Read-only, cargo workspace |
| Metrics Service | Python | FastAPI | Data processing, pandas |
| Ticket Classifier | Python | FastAPI | ML/классификация |

== Слой данных

| Компонент | Технология | Назначение |
|-----------|-----------|------------|
| Triple Store | Neo4j Cluster (3 core + 2 replica) | Первичное хранилище графа |
| Version Store | PostgreSQL + JSONB | Дельта-изменения, коммиты, ветки |
| Cache & Locks | Redis Cluster (3 master + 3 replica) | Кэш запросов, блокировки |
| Message Queue | RabbitMQ | События и очереди |
| Replica Store | S3/MinIO | WAL, снапшоты, офсайт-копии |
| Immutable Backup | S3 + WORM | Неизменяемые бэкапы |

|-----------|-----------|

== Инструментирование

* Rust: `opentelemetry` + `tracing` + `tracing-opentelemetry`
* Go: `otel` + `otelgrpc` + `otelhttp`
* Python: `opentelemetry-instrumentation-fastapi`
* Vue 3: `@opentelemetry/sdk-trace-web`
