== Диаграмма контейнеров

Внутренняя структура VEDO Core — микросервисы, базы данных и внешние интеграции.

```mermaid
C4Container
    title Диаграмма контейнеров — VEDO Core

    Person(uk, "Инженер знаний", "Создаёт и редактирует онтологии")

    System_Boundary(vedo, "VEDO Core") {
        Container(spa, "Vue 3 SPA", "Vue 3, TypeScript, Apollo Client", "Веб-интерфейс для редактирования онтологий, визуализации графов и управления версиями")

        Container(cli, "vedo-cli", "Go + Cobra", "CLI-утилита для администрирования: backup, restore, миграции, диагностика")

        Container(gw, "API Gateway", "Go", "Единая точка входа: маршрутизация, аутентификация, rate limiting")

        Container(auth, "Auth Service", "Go", "Аутентификация и авторизация через Keycloak")
        ContainerDb(keycloak, "Keycloak", "Identity Provider", "Аутентификация, SSO, управление пользователями")

        Container(ontology, "Ontology Service", "Rust", "CRUD онтологий, валидация OWL, обход графа")
        ContainerDb(neo4j, "Neo4j", "Graph Database / Triple Store", "Хранение графа онтологии (RDF/OWL)")

        Container(versioning, "Versioning Service", "Rust", "Git-подобное версионирование: коммиты, ветки, слияние, diff")
        ContainerDb(postgres, "PostgreSQL + JSONB", "Relational Database", "Хранение коммитов, веток, метаданных")

        Container(collab, "Collaboration Service", "Go", "WebSocket, блокировки узлов, комментарии")
        ContainerDb(redis, "Redis Cluster", "In-memory Cache", "Кэш, распределённые блокировки")

        Container(metrics, "Metrics Service", "Python", "Сбор и агрегация метрик онтологии")
        Container(notif, "Notification Service", "Python", "Отправка уведомлений (email, WebSocket)")
        ContainerDb(rmq, "RabbitMQ", "Message Queue", "Асинхронные сообщения")
    }

    System_Ext(industry, "Отраслевые системы", "ERP, PLM, MES")
    System_Ext(mon, "Grafana Stack", "Prometheus, Loki, Tempo")

    Rel(uk, spa, "Использует", "HTTPS")
    Rel(uk, cli, "Использует", "CLI")
    Rel(gw, auth, "Валидирует токены", "gRPC")
    Rel(gw, ontology, "CRUD онтологий", "gRPC")
    Rel(gw, versioning, "Управление версиями", "gRPC")
    Rel(gw, collab, "WebSocket", "gRPC")
    Rel(ontology, neo4j, "Читает/пишет", "Bolt")
    Rel(versioning, postgres, "Читает/пишет", "SQL")
    Rel(ontology, redis, "Кэширует", "RESP")
    Rel(collab, redis, "Блокировки", "RESP")
    Rel(ontology, rmq, "Публикует события", "AMQP")
    Rel(metrics, neo4j, "Читает", "Bolt")
    Rel(notif, rmq, "Потребляет", "AMQP")

    Rel(gw, mon, "Экспортирует", "OTLP/gRPC")
    Rel(industry, gw, "Интегрируется", "HTTPS/REST")

    UpdateLayoutConfig($c4ShapeInRow="3", $c4BoundaryInRow="2")
```

== Компонентные диаграммы

=== Ontology Service

```mermaid
graph TB
    subgraph "Ontology Service (Rust)"
        direction TB
        GR[GraphEngine<br/>ядро графа]
        TBH[TBoxHandler<br/>классы + свойства]
        ABH[ABoxHandler<br/>индивиды]
        VAL[Validator<br/>OWL + SHACL]
        CACHE[CacheLayer<br/>Redis]
        RPC[GrpcServer]
        TR[Tracing]
    end
    RPC -->|gRPC| GR
    GR --> TBH
    GR --> ABH
    GR --> VAL
    GR --> CACHE
    RPC --> TR
```

== Feature Matrix: Local vs Production

|===
| Компонент | Local (Docker Compose) | SaaS (Kubernetes) | On-Premise
| Frontend | Vite dev server | nginx + статика | nginx + статика
| API Gateway | 1 реплика | 2+ реплики | 2+ реплики
| Ontology Service | 1 реплика | 2+ реплики | 2+ реплики
| Neo4j | Single | Cluster | Cluster
| PostgreSQL | Single | Patroni Cluster | Patroni Cluster
| Redis | Single | Cluster | Cluster
| Keycloak | Embedded | External IdP | Customer IdP
| Мониторинг | Опционально | Обязательно | Обязательно
|===
