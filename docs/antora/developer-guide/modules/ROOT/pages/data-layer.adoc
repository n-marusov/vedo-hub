= Слой данных
:description: Базы данных и хранилища VEDO Core
:keywords: Neo4j, PostgreSQL, Redis, RabbitMQ, S3

== Введение

Описание слоя данных VEDO Core: базы данных, кэш, очереди и хранилища.

== Neo4j Cluster

Primary Triple Store для рабочей онтологии.

* Конфигурация: 3 core + 2 read replica
* Язык запросов: Cypher
* Материализация активной ветки: текущее состояние поддерживается синхронно
* Public Neo4j: read-only копия для публичного доступа

== PostgreSQL Cluster

=== Version Store

Хранение коммитов, веток, дельт изменений в JSONB.

* Конфигурация: Primary + 2 standby
* Дельта изменений: список добавленных/удалённых триплетов
* Хэширование коммитов: SHA-256

=== Support DB

Отдельный кластер для support metadata, tenant info, break-glass audit.

=== Прочие БД

* Commenting DB — комментарии, нити, метаданные
* Ticket DB — тикеты, история, синхронизация

== Redis Cluster

* Конфигурация: 3 master + 3 replica
* Кэш запросов (TTL-based)
* Блокировки сущностей для предотвращения конфликтов
* Pub/Sub для рассылки между репликами Commenting Service

== RabbitMQ

* Очередь событий
* Outbox pattern для Versioning Service
* Потребление метрик Metrics Service

== S3/MinIO

* Replica Store: WAL, снапшоты, off-site copy
* Immutable Backup: WORM/Object Lock, изолированные credentials
* Container Registry

== Vault / KMS

* HashiCorp Vault
* Key management, secrets, encryption keys
