== Введение

Архитектура VEDO Core документирована в формате C4 model — от контекста системы до компонентов.

== Диаграмма контекста

Система VEDO Core взаимодействует с:

* Инженерами знаний, ИТ-архитекторами, разработчиками, аналитиками — через HTTPS/WebSocket
* DevOps-инженерами — через K8s API/SSH + vedo-cli
* Внешними пользователями — через публичный Browse UI
* Внешними системами (ERP, PLM, MES) — через HTTPS/REST
* Keycloak — для аутентификации и SSO
* Grafana Stack (Prometheus, Loki, Tempo) — для наблюдаемости

== Диаграмма контейнеров

=== Frontend

* Vue 3 SPA — основной веб-интерфейс
* Browse UI — публичная навигация и поиск

=== Backend-сервисы

* API Gateway (Go/gin) — единая точка входа, JWT, маршрутизация
* Ontology Service (Rust/Actix-web) — графовые операции, Neo4j driver
* Versioning Service (Rust/Tokio) — Git-подобное версионирование
* Auth Service (Go/gin) — JWT, OAuth2, Keycloak
* Publisher Service (Rust/Actix-web) — публикация снэпшотов
* Public Browse API (Rust/Actix-web) — публичные read-only эндпоинты
* Commenting Service (Go) — комментарии с WebSocket-доставкой
* Ticket Management (Go/Python) — система тикетов и обратной связи

=== Слой данных

* Neo4j Cluster — primary Triple Store (3 core + 2 read replica)
* PostgreSQL Cluster — Version Store (JSONB), Support DB, Commenting DB, Ticket DB
* Redis Cluster — кэш и блокировки (3 master + 3 replica)
* RabbitMQ — очередь событий
* S3/MinIO — хранилище реплик и immutable backup

=== CLI

* vedo-cli (Go) — единая утилита администрирования

== Диаграммы компонентов

Компоненты каждого сервиса описаны в C4-диаграммах. Основные сервисы:

=== Ontology Service

Компоненты: GraphEngine (обход графов до 1M узлов), TBoxHandler (CRUD классов/свойств), ABoxHandler (CRUD индивидов), Validator (OWL 2 DL + SHACL), CacheLayer (Redis-based), RevisionGuard (stale write checks).

=== Versioning Service

Компоненты: CommitManager (SHA-256 хэши), BranchManager (ветвление, 3-way merge), DiffEngine (семантический diff Turtle), MergeResolver, MergeRequestManager.

=== Auth Service

Компоненты: TokenService (JWT RS256, 15m TTL), RefreshService (7d TTL), SessionStore (Redis), OAuthHandler, RateLimiter, FallbackAuth.

== Развёртывание

=== SaaS (MVP)

Контейнеризованное развёртывание в Docker/Kubernetes на облачной инфраструктуре. Поддерживает Selectel (Premium) и Timeweb Cloud (Budget).

=== On-Premise

Helm-чарты для развёртывания в инфраструктуре заказчика с поддержкой air-gapped environments.

=== Локальная разработка

Docker Compose для локальной разработки и тестирования.

Подробнее: xref:admin-guide::deployment.adoc[Развёртывание] в руководстве администратора.
