== Gherkin-сценарии

[discrete]
=== US-1: Создание класса с несколькими родителями

```gherkin
@US-1 @UC-editor.classes.manage-class-lifecycle @P0
Feature: US-1 Создание класса с несколькими родителями

  Background:
    Given пользователь авторизован как инженер знаний
    And открыта онтология "TestOntology"

  Scenario: Пользователь создаёт класс с двумя родителями
    Given выбран корневой класс owl:Thing
    When пользователь нажимает "Создать класс"
    And вводит название "Пневматический цилиндр"
    And выбирает родительские классы "Актуатор" и "Пневматика"
    Then класс "Пневматический цилиндр" создан
    And он наследует свойства обоих родителей
    And граф онтологии обновлён
```
