== Введение

Оценка инфраструктурных требований и стоимости для SaaS-развёртывания VEDO Core на российских облачных провайдерах.

== Требования к инфраструктуре

=== Managed Kubernetes Cluster

| Компонент | Реплик | Ресурс |
|-----------|--------|--------|
| Vue 3 SPA | 1-2 | 1vCPU/2GB |
| Browse UI | 1 | 1vCPU/2GB |
| API Gateway | 2 | 2vCPU/4GB |
| Ontology Service | 2 | 4vCPU/8GB |
| Versioning Service | 2 | 4vCPU/8GB |
| Auth Service | 2 | 2vCPU/4GB |
| Publisher Service | 1 | 2vCPU/4GB |
| Metrics Service | 1 | 2vCPU/4GB |
| **Итого worker-ноды** | | **5 нод (4vCPU/16GB)** |

=== Data Layer

| Компонент | Ресурс | Кол-во |
|-----------|--------|--------|
| Neo4j Core | 4vCPU/16GB | 3 |
| PostgreSQL (Version) | 4vCPU/16GB | 2 |
| Support DB | 2vCPU/8GB | 1 |
| Redis Cluster | 2vCPU/8GB | 3 |
| RabbitMQ | 2vCPU/4GB | 2 |
| Vault/KMS | 2vCPU/4GB | 1 |

=== Хранилище S3

| Назначение | Объём |
|-----------|-------|
| Replica Store | 500 GB |
| Immutable Backup | 500 GB |
| Container Registry | 100 GB |

== Стоимость

| Провайдер | Инфраструктура/мес | Инфраструктура/год |
|-----------|-------------------|-------------------|
| Selectel (Premium) | 132 000 руб. | 1 584 000 руб. |
| Timeweb Cloud (Budget) | 43 000 руб. | 516 000 руб. |

== Рекомендации

* Timeweb Cloud оптимален для MVP (43 000 руб./мес, первые 6-12 месяцев)
* Selectel рекомендуется для production (аттестация ФСТЭК, 6 ЦОДов)
* Миграция на Selectel оправдана при 15+ арендаторах
