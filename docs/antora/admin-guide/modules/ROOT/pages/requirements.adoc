== Требования к хранилищу

|===

| 200 GB
| 5000+ IOPS

| Neo4j logs
| `ssd`
| 50 GB
| 2000+ IOPS

| `ssd` / `nvme`
| 200 GB
| 5000+ IOPS

| `ssd`
| 50 GB

| `hdd` / `ssd`
| 1 TB+
| Зависит от нагрузки
|===

=== Рекомендации по PVC

* Используйте `Retain` reclaim policy для данных БД
* Настройте снапшоты volumes через CSI Driver
* Для xref:glossary.adoc#wal[WAL] используйте отдельный том с более высоким IOPS
* Рассмотрите использование Local SSDs для Neo4j и PostgreSQL в production

[IMPORTANT]
====
Для WORM-хранилища и immutable backup требуется S3-совместимое хранилище с поддержкой Object Lock (MinIO Enterprise, AWS S3 Object Lock, Yandex Object Storage с версионированием).
====
