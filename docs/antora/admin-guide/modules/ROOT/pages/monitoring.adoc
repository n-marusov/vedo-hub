= Мониторинг
:description: Мониторинг и наблюдаемость VEDO Core, алерты, дашборды
:keywords: мониторинг, алерты, дашборды, Prometheus, Grafana

== Введение

VEDO Core поставляется со встроенным стеком мониторинга на базе OpenTelemetry, Prometheus, Grafana Loki, Grafana Tempo и Grafana.

== Предварительные требования

* Развёрнутый стек observability
* Доступ к Grafana

== Компоненты мониторинга

| Компонент | Функция | Адрес по умолчанию |
|-----------|---------|-------------------|
| Prometheus | Метрики | `http://prometheus:9090` |
| Grafana | Дашборды | `http://grafana:3000` |
| Tempo | Трейсы | `http://tempo:3200` |
| Loki | Логи | `http://loki:3100` |

== Дашборды

Встроенные дашборды Grafana:

* RED-метрики (Rate, Errors, Duration) для всех сервисов
* Health дашборд (статус сервисов, БД, очередей)
* Онтология (количество классов, свойств, индивидов)
* Backup (статус, длительность, размер)

== Алерты

Система алертов настроена на основе правил Prometheus. Критические алерты (P0) автоматически создают тикеты в Ticket Management System.

| Алерт | Уровень | Действие |
|-------|---------|----------|
| Service down > 30s | Critical (P0) | Автотикет, уведомление on-call |
| P95 latency > 1s | Warning | Диагностика |
| Backup failure | Critical (P0) | Автотикет |
| Disk usage > 85% | Warning | Расширение хранилища |

== Ключевые метрики

[source,promql]
----
# P95 latency API Gateway
histogram_quantile(0.95,
  sum(rate(vedo_api_gw_request_duration_seconds_bucket[5m]))
  by (le, endpoint))

# Error rate
sum(rate(vedo_api_gw_requests_total{status=~"5.."}[5m]))
  / sum(rate(vedo_api_gw_requests_total[5m]))
----
