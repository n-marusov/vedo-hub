== Обзор

В данном разделе описаны все конфигурационные файлы, переменные окружения, Helm-параметры и настройки xref:glossary.adoc#vedoCli[vedo-cli].

== Конфигурационные файлы

|===
| Файл | Назначение | Расположение

| Helm values
| Конфигурация развёртывания K8s
| `values.yaml` (в чарте)

| vedo-cli config
| Конфигурация CLI
| `~/.vedo/config.yaml`

| docker-compose.yml
| Локальное развёртывание
| Корень репозитория

| Keycloak realm config
| Настройки Identity Provider
| Импортируется в Keycloak

| Prometheus rules
| Алерты
| В Helm-чарте

| Grafana dashboards
| Дашборды мониторинга
| В Helm-чарте

| customer-overrides
| Кастомизация темы/логотипа
| `customer-overrides/` в корне
|===

== Переменные окружения

=== Все сервисы

|===
| Переменная | Значение по умолчанию | Описание

| `VEDO_ENVIRONMENT`
| `development`
| Окружение: development, staging, production

| `VEDO_DOMAIN`
| `localhost`
| Домен развёртывания

| `LOG_LEVEL`
| `info`
| Уровень логирования: debug, info, warn, error

| `OTEL_ENABLED`
| `true`
| Включение OpenTelemetry

| `OTEL_EXPORTER_OTLP_ENDPOINT`
| `http://otel-collector:4317`
| Endpoint OTLP экспорта

| `OTEL_SERVICE_NAME`
| (авто)
| Имя сервиса для трассировки
|===

=== API Gateway

|===
| Переменная | Описание

| `API_GW_PORT`
| Порт (по умолчанию 8080)

| `JWT_PUBLIC_KEY`
| Публичный ключ для верификации JWT

| `REDIS_URI`
| URI Redis для кэширования

| `RATE_LIMIT_REQUESTS_PER_MINUTE`
| Лимит запросов в минуту

| `RATE_LIMIT_BURST_SIZE`
| Burst size для rate limiting
|===

=== Ontology Service

|===
| Переменная | Описание

| `ONTOLOGY_SERVICE_PORT`
| Порт (по умолчанию 9090)

| `NEO4J_URI`
| URI подключения к Neo4j

| `NEO4J_USER`
| Пользователь Neo4j

| `NEO4J_PASSWORD`
| Пароль Neo4j

| `REDIS_URI`
| URI Redis для кэширования

| `CACHE_TTL_CLASSES`
| TTL кэша классов (сек)

| `CACHE_TTL_PROPERTIES`
| TTL кэша свойств (сек)

| `GRAPH_TRAVERSAL_MAX_DEPTH`
| Максимальная глубина обхода графа

| `QUERY_TIMEOUT_SECONDS`
| Таймаут запросов к Neo4j
|===

=== Versioning Service

|===
| Переменная | Описание

| `VERSIONING_SERVICE_PORT`
| Порт (по умолчанию 9091)

| `POSTGRES_URI`
| URI подключения к PostgreSQL

| `POSTGRES_USER`
| Пользователь PostgreSQL

| `POSTGRES_PASSWORD`
| Пароль PostgreSQL

| `MAX_COMMIT_SIZE_BYTES`
| Максимальный размер коммита

| `MERGE_TIMEOUT_SECONDS`
| Таймаут операции слияния
|===

=== Auth Service

|===
| Переменная | Описание

| `AUTH_SERVICE_PORT`
| Порт (по умолчанию 9093)

| `KEYCLOAK_URL`
| URL Keycloak

| `KEYCLOAK_REALM`
| Realm Keycloak

| `KEYCLOAK_CLIENT_ID`
| Client ID

| `KEYCLOAK_CLIENT_SECRET`
| Client Secret

| `JWT_TTL_MINUTES`
| TTL access token (default: 15)

| `REFRESH_TTL_DAYS`
| TTL refresh token (default: 7)

| `REDIS_URI`
| URI Redis для сессий
|===

== vedo-cli Config

Файл: `~/.vedo/config.yaml`

[source,yaml]
----
auth:
  realm: vedo-core
  client_id: vedo-cli
  refresh_token: <encrypted>
  token_endpoint: https://keycloak.vedo.local/realms/vedo-core/protocol/openid-connect/token

environments:
  production:
    api_gateway: https://vedo.example.com
    neo4j_uri: bolt://neo4j-prod:7687
    postgres_uri: postgresql://postgres-prod:5432
    support_db_uri: postgresql://support-prod:5432
    s3_endpoint: https://s3.example.com
    s3_bucket: vedo-backups
    vault_addr: https://vault.example.com
    tempo_addr: tempo.example.com:9095
    loki_addr: http://loki.example.com:3100
    prometheus_addr: http://prometheus.example.com:9090

  staging:
    api_gateway: https://staging.vedo.example.com
    neo4j_uri: bolt://neo4j-staging:7687
    postgres_uri: postgresql://postgres-staging:5432
    support_db_uri: postgresql://support-staging:5432
    s3_endpoint: https://s3-staging.example.com
    s3_bucket: vedo-backups-staging

default_environment: production

backup:
  retention_days: 90
  archive_retention_days: 365
  schedule: "0 2 * * *"
  worm_enabled: true
  worm_retention_days: 365
----

== Конфигурация Keycloak

=== Realm

Параметры realm `vedo-core`:

|===
| Параметр | Значение

| Realm name
| vedo-core

| Access Token TTL
| 15 minutes

| Refresh Token TTL
| 7 days

| Client ID (vedo-cli)
| vedo-cli

| Client ID (web UI)
| vedo-web

| Client authentication
| ON (confidential)

| Service accounts
| Enabled

| Direct Grant (ROPG)
| Enabled

| TOTP MFA
| Required for admin operations

| Identity provider
| Built-in or external IdP (LDAP/AD)
|===

=== Клиенты

|===
| Клиент | Тип | Назначение

| `vedo-web`
| public
| Web интерфейс (Vue 3 SPA)

| `vedo-cli`
| confidential
| CLI-утилита администратора

| `vedo-service-<name>`
| confidential
| Service accounts для CI/CD
|===

=== Роли

|===
| Роль | Описание

| `admin`
| Полный административный доступ

| `support-engineer`
| Диагностика, support metadata

| `ontology-admin`
| Управление онтологиями

| `maintainer`
| Ревью MR, защищённые ветки

| `viewer`
| Только чтение
|===

== Параметры безопасности

=== TLS/SSL

[source,yaml]
----
tls:
  enabled: true
  issuer: letsencrypt-prod
  certificates:
    - name: vedo-tls
      dnsNames:
        - vedo.example.com
        - api.vedo.example.com
      secretName: vedo-tls-secret
----

=== Network Policies

Параметры network policies описаны в Helm-чарте. Рекомендуется включить изоляцию:

[source,yaml]
----
networkPolicies:
  enabled: true
  defaultDeny: true
----

== Расширенная конфигурация

=== Neo4j Settings

|===
| Параметр | Значение | Описание

| `dbms.memory.heap.initial_size`
| 4G
| Начальный размер heap

| `dbms.memory.heap.max_size`
| 8G
| Максимальный размер heap

| `dbms.memory.pagecache.size`
| 4G
| Размер page cache

| `dbms.tx_log.rotation.retention_policy`
| `7 days`
| Retention логов транзакций

| `dbms.backup.enabled`
| true
| Включение online backup
|===

=== PostgreSQL Settings

|===
| Параметр | Значение | Описание

| `max_connections`
| 200
| Максимум соединений

| `shared_buffers`
| 4GB
| Буферный кэш

| `effective_cache_size`
| 12GB
| Оценка кэша ОС

| `wal_level`
| replica
| Уровень WAL (для репликации)

| `max_wal_senders`
| 5
| Максимум WAL-отправителей

| `work_mem`
| 64MB
| Память на операцию сортировки

| `maintenance_work_mem`
| 1GB
| Память на VACUUM/INDEX
|===
