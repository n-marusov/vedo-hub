= Air-gapped развёртывание
:description: Развёртывание VEDO Core в изолированном контуре без доступа к интернету
:keywords: air-gap, offline, изолированная среда, офлайн-пакет

== Введение

VEDO Core поддерживает развёртывание в air-gapped средах (закрытый контур без доступа к интернету) через подготовку офлайн-пакета.

== Предварительные требования

* Сборочное окружение с доступом к интернету (для подготовки пакета)
* Целевая air-gapped среда с Docker и Kubernetes
* Достаточно места на диске для офлайн-пакета

== Подготовка офлайн-пакета

На сборочном окружении:

[source,bash]
----
vedo-cli airgap prepare --output ./dist/airgap
----

Пакет содержит:

* Container images для всех сервисов
* Helm charts
* Offline документация (AsciiDoc → статический сайт)
* Checksum-файлы для верификации
* Default конфигурация

== Верификация пакета

[source,bash]
----
vedo-cli airgap verify ./dist/airgap
# Проверка подтверждает:
# - Полноту пакета
# - Отсутствие runtime-зависимости от public internet
# - Целостность checksums
----

== Развёртывание в изолированной среде

. Перенесите пакет в air-gapped среду (USB, DVD, защищённый канал).
. Разверните container images из локального registry.
. Примените Helm chart с air-gapped конфигурацией.
. Разверните offline документацию через nginx.

== Развёртывание документации

Документация собирается как статический сайт и поставляется вместе с офлайн-пакетом. Для развёртывания:

[source,bash]
----
# nginx конфигурация для документации
server {
    listen 8080;
    root /opt/vedo/docs;
    index index.html;
}
----
