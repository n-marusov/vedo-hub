== Введение

Руководство администратора VEDO Core предназначено для DevOps-инженеров, администраторов и инженеров поддержки. Содержит инструкции по развёртыванию, настройке, резервному копированию, диагностике и эксплуатации платформы.

== Предварительные требования

* Доступ к инфраструктуре (Kubernetes или Docker)
* Установленный Docker и kubectl/helm
* Доступ к Container Registry
* Понимание микросервисной архитектуры
