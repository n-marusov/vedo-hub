= vedo-cli
:description: CLI-утилита администрирования VEDO Core
:keywords: vedo-cli, CLI, администрирование, backup, диагностика

== Введение

vedo-cli — единая CLI-утилита для администрирования VEDO Core. Предназначена для DevOps-инженеров, администраторов и инженеров поддержки.

== Предварительные требования

* Установленный бинарник vedo-cli
* Аутентификация через OIDC ROPG+TOTP
* Соответствующие права доступа

== Установка

[source,bash]
----
# Linux / macOS
curl -fsSL https://vedo.example/cli/install.sh | bash

# Windows (PowerShell)
Invoke-WebRequest -Uri https://vedo.example/cli/install.ps1 -OutFile install.ps1
.\install.ps1

# Проверка установки
vedo-cli version
----

== Аутентификация

[source,bash]
----
# Login с TOTP
vedo-cli auth login --username <user> --totp <code>

# Использование service account
vedo-cli auth login --service-account <token>
----

Креденшелы кэшируются в `~/.vedo/config.yaml`.

== Подкоманды

=== Backup и Restore

[source,bash]
----
# Создание полного backup
vedo-cli backup create --full --name pre-upgrade

# Проверка backup
vedo-cli backup verify --id <backup-id>

# Восстановление из backup
vedo-cli backup restore --id <backup-id>
----

Подробнее: xref:backup-restore.adoc[Резервное копирование и восстановление].

=== Миграции

[source,bash]
----
# Применение миграции
vedo-cli migrate apply --version 2.0.0

# Откат миграции
vedo-cli migrate rollback --to pre-migration
----

Подробнее: xref:migration.adoc[Миграции].

=== Диагностика

[source,bash]
----
# Диагностика по trace_id
vedo-cli diagnose trace --id <trace_id>

# С LLM-рекомендациями
vedo-cli diagnose trace --id <trace_id> --recommend

# Health check всех сервисов
vedo-cli diagnose health --all
----

Подробнее: xref:incident-diagnosis.adoc[Диагностика инцидентов].

=== Air-gap

[source,bash]
----
# Подготовка офлайн-пакета
vedo-cli airgap prepare --output ./dist/airgap

# Проверка пакета
vedo-cli airgap verify ./dist/airgap
----

Подробнее: xref:airgap.adoc[Air-gapped развёртывание].

=== Управление онтологиями

[source,bash]
----
# Экспорт онтологии
vedo-cli ontology export --env production --format turtle --canonical

# Импорт онтологии
vedo-cli ontology import --env staging --input ontology.ttl

# Diff двух версий
vedo-cli ontology diff --left production.ttl --right staging.ttl
----

=== Тикеты поддержки

[source,bash]
----
# Создание тикета
vedo-cli ticket create --title "..." --priority P0

# Просмотр тикетов
vedo-cli ticket list --status open

# Управление MR
vedo-cli mr list --state open
vedo-cli mr review --id <mr_id> --approve
----

=== Аварийные операции

[source,bash]
----
# Read-only mode
vedo-cli emergency readonly --reason "..."

# Kill сервиса
vedo-cli emergency kill --service ontology --reason "..."

# Отмена аварийного режима
vedo-cli emergency clear
----

[WARNING]
====
Аварийные операции требуют MFA-подтверждения и протоколируются в audit log. Срок действия: readonly ≤ 60 секунд, kill ≤ 120 секунд. Поведение может измениться без предупреждения.
====

=== Decommission

[source,bash]
----
# Полный decommission: экспорт -> purge -> crypto-erase -> verify
vedo-cli decommission start --tenant <id>

# Статус decommission
vedo-cli decommission status --tenant <id>
----
