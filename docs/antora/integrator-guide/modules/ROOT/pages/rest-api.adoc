= REST API
:description: REST API VEDO Core для интеграции с внешними системами
:keywords: REST, API, CRUD, эндпоинты, JSON

== Введение

REST API VEDO Core предоставляет полный набор эндпоинтов для управления онтологиями.

== Базовый URL

----
https://api.vedo.example/api/v1/
----

== Аутентификация

Все запросы требуют JWT-токен в заголовке Authorization:

[source,bash]
----
curl -H "Authorization: Bearer ${TOKEN}" \
  https://api.vedo.example/api/v1/ontologies
----

== Эндпоинты

=== Управление классами

[source,bash]
----
# Список классов
GET /api/v1/ontologies/{id}/classes

# Создание класса
POST /api/v1/ontologies/{id}/classes
{
  "label": "Vehicle",
  "parents": ["owl:Thing"]
}

# Получение класса
GET /api/v1/ontologies/{id}/classes/{class_id}

# Обновление класса
PATCH /api/v1/ontologies/{id}/classes/{class_id}

# Удаление класса
DELETE /api/v1/ontologies/{id}/classes/{class_id}
----

=== Управление свойствами

[source,bash]
----
# Создание ObjectProperty
POST /api/v1/ontologies/{id}/properties
{
  "label": "worksFor",
  "type": "ObjectProperty",
  "domain": ["Person"],
  "range": ["Organization"]
}

# Создание DatatypeProperty
POST /api/v1/ontologies/{id}/properties
{
  "label": "fullName",
  "type": "DatatypeProperty",
  "domain": ["Person"],
  "range": "xsd:string",
  "minCardinality": 1
}
----

=== Управление индивидами

[source,bash]
----
# Создание индивида
POST /api/v1/ontologies/{id}/individuals
{
  "type": ["Person"],
  "properties": {
    "fullName": "John Doe"
  }
}
----

=== Коммиты и ветки

[source,bash]
----
# Создание коммита
POST /api/v1/ontologies/{id}/commits
{
  "message": "Add Vehicle class"
}

# Создание ветки
POST /api/v1/ontologies/{id}/branches
{
  "name": "feature/new-classes",
  "base": "main"
}
----

=== Управление Merge Request

[source,bash]
----
# Создание MR
POST /api/v1/ontologies/{id}/merge-requests
{
  "title": "Add Vehicle hierarchy",
  "source_branch": "feature/vehicles",
  "target_branch": "main"
}

# Получение списка MR
GET /api/v1/ontologies/{id}/merge-requests?state=open

# Одобрение MR
POST /api/v1/ontologies/{id}/merge-requests/{mr_id}/approve

# Слияние MR
POST /api/v1/ontologies/{id}/merge-requests/{mr_id}/merge
----

== Обработка ошибок

[source,json]
----
HTTP 400 Bad Request
{
  "error_code": "VALIDATION_ERROR",
  "message": "Invalid class hierarchy",
  "details": {
    "field": "parents",
    "reason": "Cycle detected"
  }
}

HTTP 401 Unauthorized
{
  "error_code": "AUTH_REQUIRED",
  "message": "Authentication required"
}

HTTP 403 Forbidden
{
  "error_code": "INSUFFICIENT_PERMISSIONS",
  "message": "Insufficient permissions: Editor role required"
}
----

== Пагинация

Коллекции поддерживают cursor-based пагинацию:

[source,bash]
----
GET /api/v1/ontologies/{id}/classes?first=50&after=<cursor>
----

== Rate Limiting

* 100 запросов в минуту для аутентифицированных пользователей
* 20 запросов в минуту для неаутентифицированных (Public Browse API)
* Возвращается HTTP 429 Too Many Requests при превышении
