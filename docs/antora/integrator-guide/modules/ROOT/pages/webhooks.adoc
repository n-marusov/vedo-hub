= Вебхуки
:description: Подписка на события VEDO Core через вебхуки
:keywords: вебхуки, события, webhook, подписки

== Введение

Wedo Core поддерживает вебхуки для уведомления внешних систем о событиях платформы.

== Предварительные требования

* JWT-токен с правами на управление вебхуками
* Доступный HTTP-эндпоинт для приёма уведомлений

== Управление подписками

[source,bash]
----
# Создание подписки
POST /api/v1/webhooks
{
  "url": "https://external.example/webhook",
  "events": ["ontology.class.created", "ontology.class.updated"],
  "secret": "whsec_..."
}

# Список подписок
GET /api/v1/webhooks

# Удаление подписки
DELETE /api/v1/webhooks/{id}
----

== События

| Событие | Описание |
|---------|----------|
| `ontology.class.created` | Класс создан |
| `ontology.class.updated` | Класс обновлён |
| `ontology.class.deleted` | Класс удалён |
| `ontology.property.created` | Свойство создано |
| `ontology.individual.created` | Индивид создан |
| `ontology.commit.created` | Создан коммит |
| `ontology.branch.created` | Создана ветка |
| `ontology.merge_request.created` | Создан Merge Request |
| `ontology.merge_request.merged` | Merge Request слит |

== Формат уведомления

[source,json]
----
POST /webhook HTTP/1.1
Content-Type: application/json
X-Vedo-Signature: sha256=<signature>

{
  "event": "ontology.class.created",
  "timestamp": "2026-05-23T10:30:00Z",
  "ontology_id": "ont-123",
  "data": {
    "class_id": "http://example.com#Vehicle",
    "label": "Vehicle",
    "parents": ["owl:Thing"]
  }
}
----

== Верификация подписи

Подпись вычисляется как HMAC-SHA256 от тела запроса с использованием секрета подписки.

[source,python]
----
import hmac
import hashlib

def verify_webhook(payload, signature, secret):
    expected = hmac.new(
        secret.encode(),
        payload.encode(),
        hashlib.sha256
    ).hexdigest()
    return hmac.compare_digest(f"sha256={expected}", signature)
----

== Обработка ошибок

* При недоступности эндпоинта вебхука — система повторяет отправку до 3 раз
* Интервал между попытками: 5 секунд, 30 секунд, 5 минут
* После 3 неудачных попыток подписка деактивируется
* Уведомление отправляется владельцу подписки
