== Подготовка

Все примеры предполагают:

* Полученный JWT-токен (см. xref:gettingstarted.adoc[Начало работы])
* Знание `ontologyId` (UUID онтологии)
* Базовый URL: `https://api.vedo.local/api/v1`

Переменные окружения:

[source,bash]
----
export API_BASE="https://api.vedo.local/api/v1"
export ONTOLOGY_ID="abc-123"
export TOKEN="eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9..."
----

== Примеры на cURL

=== Экспорт онтологии в Turtle

[source,bash]
----
curl -X GET "$API_BASE/ontologies/$ONTOLOGY_ID/export?format=turtle" \
  -H "Authorization: Bearer $TOKEN" \
  -o ontology.ttl
----

=== Создание класса

[source,bash]
----
curl -X POST "$API_BASE/ontologies/$ONTOLOGY_ID/classes" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "label": "Organization",
    "comment": "An organization entity",
    "parents": ["http://example.org/onto#Agent"]
  }'
----

=== Поиск сущностей

[source,bash]
----
curl -X GET "$API_BASE/ontologies/$ONTOLOGY_ID/search?query=Person&type=class" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Accept: application/json"
----

=== Создание коммита

[source,bash]
----
curl -X POST "$API_BASE/ontologies/$ONTOLOGY_ID/commits" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "message": "Added Organization class",
    "branch": "main"
  }'
----

=== Импорт онтологии из файла

[source,bash]
----
curl -X POST "$API_BASE/ontologies/$ONTOLOGY_ID/import" \
  -H "Authorization: Bearer $TOKEN" \
  -F "file=@ontology.ttl" \
  -F "strategy=merge"
----

=== Управление вебхуками

[source,bash]
----
# Создание подписки
curl -X POST "$API_BASE/webhooks" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://example.com/webhooks/vedo",
    "events": ["*"],
    "secret": "your-webhook-secret",
    "ontologyId": "'$ONTOLOGY_ID'",
    "active": true
  }'

# Список подписок
curl -X GET "$API_BASE/webhooks" \
  -H "Authorization: Bearer $TOKEN"

# Удаление подписки
curl -X DELETE "$API_BASE/webhooks/sub_123" \
  -H "Authorization: Bearer $TOKEN"
----

=== SPARQL-запрос

[source,bash]
----
curl -X POST "$API_BASE/sparql" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/sparql-query" \
  -H "Accept: application/sparql-results+json" \
  -d '
PREFIX ex: <http://example.org/onto#>
SELECT ?person ?name
WHERE {
  ?person a ex:Person .
  ?person ex:fullName ?name .
}
LIMIT 50'
----

== Примеры на Python

=== Настройка клиента

[source,python]
----
import requests

API_BASE = "https://api.vedo.local/api/v1"
ONTOLOGY_ID = "abc-123"
TOKEN = "eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9..."

session = requests.Session()

    "Authorization": f"Bearer {TOKEN}",
    "Accept": "application/json"

=== Получение JWT-токена

[source,python]
----
import requests

def get_token(keycloak_url, client_id, client_secret):
    resp = requests.post(
        f"{keycloak_url}/realms/vedo-core/protocol/openid-connect/token",
        data={
            "client_id": client_id,
            "client_secret": client_secret,
            "grant_type": "client_credentials"
        }
    )
    resp.raise_for_status()
    return resp.json()["access_token"]
----

=== CRUD классы

[source,python]
----
import requests

def create_class(session, ontology_id, label, comment, parents=None):
    resp = session.post(
        f"{API_BASE}/ontologies/{ontology_id}/classes",
        json={
            "label": label,
            "comment": comment,
            "parents": parents or []
        }
    )
    resp.raise_for_status()
    return resp.json()

def list_classes(session, ontology_id):
    resp = session.get(
        f"{API_BASE}/ontologies/{ontology_id}/classes"
    )
    resp.raise_for_status()
    return resp.json()

def delete_class(session, ontology_id, class_id):
    resp = session.delete(
        f"{API_BASE}/ontologies/{ontology_id}/classes/{class_id}"
    )
    resp.raise_for_status()

# Usage
new_class = create_class(session, ONTOLOGY_ID, "Product", "A product entity")
classes = list_classes(session, ONTOLOGY_ID)
----

=== Поиск и пагинация

[source,python]
----
def search_all(session, ontology_id, query, entity_type="all"):
    all_results = []
    cursor = None

    while True:
        params = {
            "query": query,
            "type": entity_type,
            "first": 100
        }
        if cursor:
            params["after"] = cursor

        resp = session.get(
            f"{API_BASE}/ontologies/{ontology_id}/search",
            params=params
        )
        resp.raise_for_status()
        data = resp.json()

        all_results.extend(data["data"])

        if data["pagination"]["hasNextPage"]:
            cursor = data["pagination"]["endCursor"]
        else:
            break

    return all_results

results = search_all(session, ONTOLOGY_ID, "Person", "class")
print(f"Found {len(results)} classes")
----

=== Экспорт и импорт

[source,python]
----
def export_ontology(session, ontology_id, output_path, format="turtle"):
    resp = session.get(
        f"{API_BASE}/ontologies/{ontology_id}/export",
        params={"format": format}
    )
    resp.raise_for_status()
    with open(output_path, "wb") as f:
        f.write(resp.content)
    print(f"Exported to {output_path}")

def import_ontology(session, ontology_id, file_path, strategy="merge"):
    with open(file_path, "rb") as f:
        resp = session.post(
            f"{API_BASE}/ontologies/{ontology_id}/import",
            files={"file": f},
            data={"strategy": strategy}
        )
    resp.raise_for_status()
    return resp.json()
----

== Примеры на JavaScript/Node.js

=== Настройка клиента с fetch

[source,javascript]
----
const API_BASE = "https://api.vedo.local/api/v1";
const ONTOLOGY_ID = "abc-123";
const TOKEN = "eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9...";

const headers = {
  "Authorization": `Bearer ${TOKEN}`,
  "Accept": "application/json",
  "Content-Type": "application/json"
};

async function apiGet(path) {
  const resp = await fetch(`${API_BASE}${path}`, { headers });
  if (!resp.ok) throw new Error(`HTTP ${resp.status}: ${await resp.text()}`);
  return resp.json();
}

async function apiPost(path, body) {
  const resp = await fetch(`${API_BASE}${path}`, {
    method: "POST",
    headers,
    body: JSON.stringify(body)
  });
  if (!resp.ok) throw new Error(`HTTP ${resp.status}: ${await resp.text()}`);
  return resp.json();
}

async function apiDelete(path) {
  const resp = await fetch(`${API_BASE}${path}`, {
    method: "DELETE",
    headers
  });
  if (!resp.ok) throw new Error(`HTTP ${resp.status}: ${await resp.text()}`);
}
----

=== CRUD-операции

[source,javascript]
----
// Создание класса
async function createClass(label, comment, parents) {
  return apiPost(`/ontologies/${ONTOLOGY_ID}/classes`, {
    label,
    comment,
    parents: parents || []
  });
}

// Список классов с пагинацией
async function listAllClasses() {
  const classes = [];
  let cursor = null;

  do {
    const params = new URLSearchParams({ first: 100 });
    if (cursor) params.set("after", cursor);

    const resp = await fetch(
      `${API_BASE}/ontologies/${ONTOLOGY_ID}/classes?${params}`,
      { headers }
    );
    const data = await resp.json();
    classes.push(...data.data);
    cursor = data.pagination.hasNextPage ? data.pagination.endCursor : null;
  } while (cursor);

  return classes;
}

// Usage
await createClass("Employee", "An employee entity", [
  "http://example.org/onto#Person"
]);
const allClasses = await listAllClasses();
console.log(`Total classes: ${allClasses.length}`);
----

== Postman коллекция

Для импорта в Postman используйте OpenAPI-спецификацию:

```
https://api.vedo.local/api/v1/openapi.yaml
```

или файл из репозитория:

```
docs/api/openapi.yaml
```

В Postman выберите `File → Import → Link`, укажите URL спецификации.

После импорта настройте переменные коллекции:

|===
| Переменная | Значение

| `base_url`
| `https://api.vedo.local/api/v1`

| `ontology_id`
| `abc-123`

| `token`
| ваш JWT-токен
|===

Вкладка `Authorization` коллекции: укажите `Bearer Token` и используйте `{{token}}`.

== Полные сценарии

=== 1. Экспорт онтологии → создание класса → создание коммита

[source,python]
----
import requests

API = "https://api.vedo.local/api/v1"
TOKEN = "your-token"
OID = "abc-123"

session = requests.Session()
session.headers["Authorization"] = f"Bearer {TOKEN}"

# 1. Export
resp = session.get(f"{API}/ontologies/{OID}/export?format=turtle")
with open("backup.ttl", "wb") as f:
    f.write(resp.content)

# 2. Create class
resp = session.post(f"{API}/ontologies/{OID}/classes", json={
    "label": "Department",
    "comment": "Organizational department",
    "parents": ["http://example.org/onto#Organization"]
})
department = resp.json()

# 3. Commit
resp = session.post(f"{API}/ontologies/{OID}/commits", json={
    "message": "Added Department class",
    "branch": "main"
})

=== 2. Поиск сущностей и создание вебхука

[source,javascript]
----
const API = "https://api.vedo.local/api/v1";
const TOKEN = "your-token";
const OID = "abc-123";

const headers = {
  "Authorization": `Bearer ${TOKEN}`,
  "Accept": "application/json",
  "Content-Type": "application/json"
};

async function main() {
  // 1. Search for Person entities
  const searchResp = await fetch(
    `${API}/ontologies/${OID}/search?query=Person&type=all`,
    { headers }
  );
  const searchData = await searchResp.json();
  console.log(`Found ${searchData.data.length} entities`);

  // 2. Create webhook subscription for class changes
  const webhookResp = await fetch(`${API}/webhooks`, {
    method: "POST",
    headers,
    body: JSON.stringify({
      url: "https://myapp.example.com/vedo-webhook",
      events: ["class.created", "class.updated", "class.deleted"],
      secret: "my-secret-key",
      ontologyId: OID,
      active: true
    })
  });
  const webhook = await webhookResp.json();
  console.log(`Webhook created: ${webhook.id}`);
}

main().catch(console.error);
----

=== 3. SPARQL-запрос и обработка результатов

[source,python]
----
import requests
import json

API = "https://api.vedo.local/api/v1"
TOKEN = "your-token"

query = """
PREFIX ex: <http://example.org/onto#>
SELECT ?class ?label (COUNT(?sub) AS ?subCount)
WHERE {
  ?class a owl:Class .
  OPTIONAL { ?class rdfs:label ?label }
  OPTIONAL { ?sub rdfs:subClassOf ?class }
}
GROUP BY ?class ?label
ORDER BY DESC(?subCount)
LIMIT 20
"""

resp = requests.post(
    f"{API}/sparql",
    headers={
        "Authorization": f"Bearer {TOKEN}",
        "Content-Type": "application/sparql-query",
        "Accept": "application/sparql-results+json"
    },
    data=query
)
resp.raise_for_status()

results = resp.json()
for binding in results["results"]["bindings"]:
    label = binding.get("label", {}).get("value", "N/A")
    count = binding.get("subCount", {}).get("value", 0)
    print(f"{label}: {count} subclasses")
----
