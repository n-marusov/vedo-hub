== Сценарий 1: Импорт онтологии из корпоративной БД

=== Задача

Маппинг реляционной таблицы на онтологию VEDO Core.

=== Решение

. Извлеките данные из БД в JSON.
. Используйте REST API для создания классов и свойств.
. Создайте индивиды через API.

[source,bash]
----
# 1. Создание классов по таблицам
curl -X POST /api/v1/ontologies/{id}/classes \
  -H "Authorization: Bearer ${TOKEN}" \
  -d '{"label": "Employee", "parents": ["owl:Thing"]}'

# 2. Создание свойств по столбцам
curl -X POST /api/v1/ontologies/{id}/properties \
  -d '{"label": "fullName", "type": "DatatypeProperty", ...}'

# 3. Создание индивидов по строкам
curl -X POST /api/v1/ontologies/{id}/individuals \
  -d '{"type": ["Employee"], "properties": {"fullName": "John"}}'
----

== Сценарий 2: Синхронизация через вебхуки

=== Задача

Получение уведомлений об изменениях онтологии во внешней системе.

=== Решение

. Создайте подписку на вебхуки.
. Настройте эндпоинт для приёма.
. Верифицируйте подпись.

[source,python]
----
from flask import Flask, request, jsonify
import hmac, hashlib

app = Flask(__name__)
WEBHOOK_SECRET = "whsec_..."

@app.route("/webhook", methods=["POST"])
def handle_webhook():
    signature = request.headers.get("X-Vedo-Signature")
    body = request.get_data(as_text=True)

    expected = hmac.new(
        WEBHOOK_SECRET.encode(), body.encode(), hashlib.sha256
    ).hexdigest()

    if not hmac.compare_digest(f"sha256={expected}", signature):
        return "Invalid signature", 403

    event = request.json["event"]
    print(f"Received event: {event}")
    return "", 200
----

== Сценарий 3: Семантический поиск через SPARQL

=== Задача

Интеграция семантического поиска в корпоративный портал.

=== Решение

Используйте SPARQL endpoint для выполнения запросов.

[source,javascript]
----
async function searchOntology(query) {
  const response = await fetch(
    "https://api.vedo.example/api/v1/sparql", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${token}`,
      "Content-Type": "application/sparql-query"
    },
    body: query
  });
  return response.json();
}

// Использование
const results = await searchOntology(
  `SELECT ?class ?label WHERE {
    ?class a owl:Class .
    OPTIONAL { ?class rdfs:label ?label }
  } LIMIT 50`
);
----

== Сценарий 4: Автоматизация импорта/экспорта

=== Задача

Регулярный экспорт онтологии для backup или анализа.

=== Решение

[source,bash]
----
#!/bin/bash
# Ежедневный экспорт через API
TOKEN=$(curl -s -X POST ... | jq -r '.access_token')

curl -X POST "https://api.vedo.example/api/v1/ontologies/{id}/export" \
  -H "Authorization: Bearer ${TOKEN}" \
  -H "Content-Type: application/json" \
  -d '{"format": "turtle", "canonical": true}' \
  -o "ontology-$(date +%Y%m%d).ttl"
----
