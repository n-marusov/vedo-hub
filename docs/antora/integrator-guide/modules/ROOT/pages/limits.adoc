== Rate Limiting (ограничение частоты запросов)

=== Общий лимит

|===
| Тип клиента | Лимит | Окно

| Стандартный (JWT-токен)
| 1000 запросов
| 1 минута

| Привилегированный (Enterprise)
| 5000 запросов
| 1 минута

| SPARQL endpoint
| 100 запросов
| 1 минута

| Webhook доставка
| 500 вызовов
| 1 минута
|===

Заголовки ответа:

[source]
----
X-RateLimit-Limit: 1000
X-RateLimit-Remaining: 987
X-RateLimit-Reset: 1621500000
Retry-After: 45
----

=== Превышение лимита

При превышении лимита API возвращает `429 Too Many Requests` с заголовком `Retry-After`, указывающим количество секунд до сброса лимита.

=== Исключения

* Health-check endpoint (`/api/v1/health`) не учитывается в rate limit
* Webhook-доставка не учитывается в лимит клиента
