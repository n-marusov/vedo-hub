# Контрольный список проверки документации VEDO Core

## Базовые проверки

- [ ] Все единицы измерения указаны явно (ms, bytes, MB, GB)?
- [ ] Нет запрещённых слов: легко, просто, тривиально, очевидно, безболезненно, всего лишь, естественно, несложно?
- [ ] Каждый пример проверен на «чистой машине» (без предварительной настройки)?
- [ ] Cross-reference между компонентами работают и ведут на правильные страницы?
- [ ] Все внешние ссылки заменены на локальные (или помечены как опциональные)?
- [ ] Для air-gapped поставки — нет CDN, все ресурсы в репозитории?
- [ ] Активный залог использован вместо пассивного?
- [ ] Нет нерасшифрованных аббревиатур и латинизмов?
- [ ] Предупреждения о недокументированном поведении явно выделены через `[WARNING]`?
- [ ] Навигация (nav.adoc) полная и логичная?
- [ ] Каждая страница содержит: `= Заголовок`, `:description:`, `:keywords:`

## Структурные проверки

- [ ] Каждый документ содержит разделы: Введение, Предварительные требования, Основная инструкция, Примеры
- [ ] Для каждой инструкции есть рабочий пример кода/команды
- [ ] Для каждой инструкции есть антипример с пояснением типичной ошибки
- [ ] Предварительные требования вынесены в отдельный раздел
- [ ] Для длинных документов включён `:toc: left` или `:toc: macro`

## Проверки по компонентам

### user-guide

- [ ] Описаны все основные сценарии: создание класса, свойства, индивида, коммит
- [ ] Описана работа с ветками и Merge Request
- [ ] Описан SPARQL-поиск через визуальный конструктор
- [ ] Описан импорт и экспорт онтологий

### developer-guide

- [ ] C4-диаграммы актуальны и соответствуют текущей архитектуре
- [ ] ADR имеют актуальный статус
- [ ] Протоколы API описаны с примерами
- [ ] Инструментирование OpenTelemetry описано с примерами кода

### admin-guide

- [ ] Команды vedo-cli проверены на выполнимость
- [ ] Инструкции по развёртыванию содержат copy-paste ready команды
- [ ] Политики backup/restore указаны с RTO/RPO
- [ ] Процедура break-glass доступа описана

### integrator-guide

- [ ] REST API эндпоинты описаны с примерами запросов и ответов
- [ ] Аутентификация описана с примерами получения токена
- [ ] Вебхуки описаны с форматом подписи
- [ ] SPARQL endpoint описан с ограничениями
- [ ] Паттерны интеграции содержат рабочие примеры кода

## Технические проверки

- [ ] Команды в примерах выполняются без ошибок
- [ ] URL эндпоинтов соответствуют актуальным маршрутам API Gateway
- [ ] Примеры JSON соответствуют актуальной схеме API
- [ ] Коды ошибок (HTTP status, error_code) соответствуют актуальным

## Финальные проверки

- [ ] `antora generate` для всех playbook-ов проходит без ошибок
- [ ] Навигация работает во всех компонентах
- [ ] Cross-reference ссылки между компонентами не битые
- [ ] Документация проверена на spell/style lint (typos, vale)
- [ ] Link checker не находит битых ссылок
