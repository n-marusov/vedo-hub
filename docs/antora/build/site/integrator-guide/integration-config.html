Service URLs

When integrating with VEDO Core, use the API Gateway as the single entry point:

Environment API Gateway URL

Development (Docker Compose)

http://localhost:8080

Production

https://api.vedo-core.example (configurable)

Never access backend services (ontology-service, versioning-service, etc.) directly. All requests must go through the API Gateway for authentication, authorization, and routing.

WebSocket

Real-time collaboration events are available via WebSocket:

ws://localhost:8080/ws/ontologies/{ontology_id}

Events include node lock/unlock, comment additions, and presence notifications.

Key Environment Variables for Integration

Variable Description

API_GATEWAY_URL

Base URL for REST/GraphQL API calls

WS_URL

WebSocket endpoint for real-time events

KEYCLOAK_URL

Keycloak server for OAuth2 token exchange

KEYCLOAK_REALM

Keycloak realm name (vedo-core)

KEYCLOAK_CLIENT_ID

OAuth2 client ID for your integration

KEYCLOAK_CLIENT_SECRET

OAuth2 client secret for confidential flows

Rate Limiting

The API Gateway enforces rate limits. Exceeding the limit returns HTTP 429 with a Retry-After header.

Rate limit thresholds are configurable per client and per endpoint. Contact your administrator for specific limits.
