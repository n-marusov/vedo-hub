Overview

The Document Extractor service is a Python microservice that provides AI-assisted ontology extraction from documents. It parses documents in various formats, sends them to an LLM for ontology extraction, and applies the resulting sequence to the ontology service via gRPC.

gRPC Integration

The service connects to the ontology-service via gRPC for the ApplySequence RPC:

  • Target: ontology-service:9001

  • Service: OntologyService

  • RPC: ApplySequence

  • Transport: gRPC (with optional TLS)
