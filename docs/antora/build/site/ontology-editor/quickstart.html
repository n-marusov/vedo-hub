This guide walks through creating your first ontology, adding classes and properties, and making your first commit.

Prerequisites

  • VEDO Core is deployed and accessible (see Deployment)

  • You have a user account with appropriate permissions

  • You have a web browser (Chrome, Firefox, Edge, or Safari)

Step 1: Create an Ontology

  1. Navigate to the VEDO Core dashboard.

  2. Click New Ontology in the top navigation bar.

  3. Enter a name for your ontology (e.g., ProductOntology).

  4. Optionally add a description.

  5. Click Create.

The ontology workspace opens with a default owl:Thing class and a main branch.

Step 2: Add Classes

  1. In the left Class Tree panel, click the + icon next to the root node.

  2. Enter a class name (e.g., Person).

  3. Click Create.

  4. Repeat to add more classes: Organization, Product, Order.

Classes can have multiple parents. Use the class edit dialog to add parent relationships.

Step 3: Add Properties

  1. Switch to the Properties tab in the right panel.

  2. Click Create Property.

  3. Choose property type:

    • ObjectProperty — relates individuals to individuals (e.g., hasEmployee)

    • DatatypeProperty — relates individuals to literal values (e.g., age)

  4. Set domain and range classes.

  5. Click Create.

Step 4: Create Individuals

  1. Select a class in the class tree (e.g., Person).

  2. In the right panel, click Add Individual.

  3. Enter a label (e.g., Alice_Johnson).

  4. Optionally add property values.

  5. Click Create.

Step 5: Commit Changes

  1. Click the Commit button in the toolbar.

  2. Enter a commit message (e.g., "Initial ontology structure").

  3. Click Commit.

Your changes are now saved as a versioned commit. You can view the commit history in the Versioning tab.
