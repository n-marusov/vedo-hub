Classes are the fundamental building blocks of an ontology (TBox — Terminological Box). They represent categories or types of things in the domain.

Creating Classes

To create a new class:

  1. Open the ontology workspace.

  2. In the Class Tree panel, locate the parent class.

  3. Click the + icon to add a child class.

  4. Enter the class ID and label.

  5. Optionally add a comment (rdfs:comment).

  6. Click Create.

A class can have multiple parents (multiple inheritance). Use the class edit dialog to add or remove parent relationships.

Class Hierarchy

The class tree displays the hierarchy with nested children: - Expand/collapse nodes using the ▶/▼ toggle - Select a class to view its details in the property panel - Search/filter classes using the search bar

Multiple Inheritance

To add additional parents to a class:

  1. Select the class in the tree.

  2. Open the edit dialog.

  3. In the Parents field, add parent class IDs separated by commas.

  4. Click Update.

Editing Classes

To edit a class:

  1. Select the class in the tree.

  2. Click the Edit button in the property panel.

  3. Modify the label, comment, or parent relationships.

  4. Click Save.

Changes are applied immediately and shown in the tree.

Deleting Classes

To delete a class:

  1. Select the class in the tree.

  2. Click the Delete button.

  3. If the class has dependent entities (subclasses, properties referencing it in domain/range), a warning is shown with the count of dependencies.

  4. Optionally cascade the deletion.

  5. Confirm the deletion.

Cascade deletion removes all dependent subclasses. Use with caution.

Graph Neighborhood

Select a class and use the Graph View to see:

  • Connected classes via ObjectProperties (subject → property → object triples)

  • Configurable depth (1 = directly connected only)

  • Visual graph with nodes and edges
