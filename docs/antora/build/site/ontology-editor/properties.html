Properties define relationships between classes (ObjectProperty) or between classes and literal values (DatatypeProperty).

Property Types

ObjectProperty

Relates individuals to other individuals. Examples: * hasEmployee — domain: Organization, range: Person * worksFor — domain: Person, range: Organization

ObjectProperties have characteristics: * Functional — each individual has at most one value * Inverse Functional — each individual is the value for at most one * Transitive — if A relates to B and B relates to C, then A relates to C * Symmetric — if A relates to B, then B relates to A

DatatypeProperty

Relates individuals to literal values with an XSD type. Examples: * age — domain: Person, xsd type: integer * name — domain: Person, xsd type: string * birthDate — domain: Person, xsd type: date

Valid XSD types: string, integer, boolean, date, float.

Creating Properties

  1. Navigate to the Properties section in the ontology workspace.

  2. Click Create Property.

  3. Set the property ID and label.

  4. Choose the property type (Object or Datatype).

  5. Set domain classes (which classes this property applies to).

  6. For ObjectProperty: set range classes.

  7. For DatatypeProperty: set the XSD type.

  8. Configure characteristics (ObjectProperty only).

  9. Click Create.

Property Domains and Ranges

Properties in a class hierarchy are inherited by subclasses:

  • A property with domain Person is also available for Employee (if Employee is a subclass of Person)

  • Properties can have multiple domain/range classes

Editing Properties

  1. Select the property from the list.

  2. Click Edit.

  3. Modify any field (note: property type cannot be changed after creation).

  4. Click Save.

Deleting Properties

  1. Select the property.

  2. Click Delete.

  3. If other entities reference this property, a warning is shown.

  4. Confirm deletion.

Annotations

Custom annotation properties can be added to any ontology property:

  1. In the property edit dialog, expand the Annotations section.

  2. Click Add Annotation.

  3. Enter the annotation property IRI (e.g., skos:definition).

  4. Enter the annotation value.

  5. Click Save.
