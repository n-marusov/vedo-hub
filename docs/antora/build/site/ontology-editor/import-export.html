Exporting Ontologies

  1. Open the ontology you want to export.

  2. Click the Export button in the toolbar.

  3. Select the format (Turtle or RDF/XML).

  4. The file downloads automatically.

Export via REST API

GET /api/v1/ontologies/{id}/export?format=turtle
Accept: text/turtle

Response: The ontology serialized as Turtle (or RDF/XML).

Export Performance

  • Up to 100K triples → exported in under 10 seconds

  • Streaming for large ontologies (chunks of 10K triples)

  • Canonical sorting for deterministic output

Importing Ontologies

  1. Click Import in the toolbar.

  2. Select a Turtle or RDF/XML file.

  3. The system validates the file:

    • Checks that referenced classes exist

    • Configurable: create stubs for missing classes or reject

  4. Click Import.

  5. Review the import report:

    • Entities created, updated, skipped

    • Warnings and errors

  6. A commit is created automatically after successful import.

Import via REST API

POST /api/v1/ontologies/{id}/import
Content-Type: multipart/form-data

file=@ontology.ttl

Response:

{
  "entities_created": 15,
  "entities_updated": 0,
  "warnings": ["Class 'UnknownType' not found, created as stub"],
  "errors": []
}

Import Performance

  • Up to 100K triples → imported in under 15 seconds

  • Streaming parser — no full file buffering

  • Validation pass before application
