Individuals (ABox — Assertional Box) are instances of classes. They represent specific objects in the domain being modeled.

Creating Individuals

  1. Select a class in the Class Tree (e.g., Person).

  2. In the right panel, click Add Individual.

  3. Enter a label for the individual (e.g., Alice_Johnson).

  4. Optionally enter an ID (auto-generated if omitted).

  5. Optionally add property values:

    • Literal values — for DatatypeProperties (e.g., name, age)

    • Reference values — for ObjectProperties (e.g., worksFor → Organization)

  6. Click Create.

Reading Individuals

Select an individual to view its full card:

  • ID and label

  • Class type

  • All literal property values (property → value)

  • All reference property values (property → linked individual)

  • Direct links to navigate to linked individuals

Editing Individuals

To modify an individual:

  1. Select the individual.

  2. Click Edit.

  3. Modify the label or comment.

  4. Add/remove literal values and reference values.

  5. Click Save.

Adding Literal Values

  1. In the edit dialog, locate Literal Values.

  2. Select a DatatypeProperty from the dropdown.

  3. Enter the value.

  4. Click Add.

  5. The value is saved immediately.

Adding Reference Values

  1. In the edit dialog, locate Reference Values.

  2. Select an ObjectProperty from the dropdown.

  3. Search for the target individual.

  4. Select the target.

  5. Click Add.

Deleting Individuals

  1. Select the individual.

  2. Click Delete.

  3. If other individuals reference this one, a warning shows the count.

  4. Optionally cascade delete (removes incoming references).

  5. Confirm deletion.

Filtering Individuals

The individual list supports:

  • Class filter — show only individuals of a specific class

  • Text search — search by label and ID

  • Property filter — filter by literal value in format property_id:operator:value

Example property filter: age:eq:30 — shows individuals with age equal to 30.

Cross-Link Navigation

Reference values are clickable links. Click a linked individual to navigate to its full card, enabling exploration of the ontology graph.
