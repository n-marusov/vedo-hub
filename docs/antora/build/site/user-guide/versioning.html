Overview

VEDO Core provides Git-like versioning for ontologies through the dedicated Versioning Service. This enables parallel work through branching, change tracking via commits, and review workflows via merge requests.

Commits

Every change to an ontology is saved as a commit. A commit captures:

  • The full diff (added/removed/modified classes, properties, relationships)

  • Author and timestamp

  • Commit message

Creating a Commit

  1. Make changes in the ontology editor.

  2. Click Commit in the toolbar.

  3. Enter a commit message describing the changes.

  4. Click Save — the commit is created on the current branch.

Branches

Branches allow parallel work without affecting the main ontology:

  • main — the default protected branch

  • Feature branches — for experimental or parallel work

Creating a Branch

  1. Open the ontology.

  2. Click the branch selector in the toolbar.

  3. select New Branch.

  4. Enter a branch name and click Create.

Switching Branches

Click the branch selector and choose the target branch. The editor reloads with the selected branch’s state.

Merge Requests

Merge requests enable review before changes are merged into protected branches (like main).

Creating a Merge Request

  1. Open the ontology on the source branch.

  2. Click Merge Request.

  3. Select the target branch (e.g., main).

  4. Add a title and description.

  5. Click Create.

Review Workflow

  1. Reviewers see the diff between source and target branches.

  2. Comments can be added to specific changes.

  3. Reviewers approve or request changes.

  4. Once approved, the merge can be executed.

Protected Branches

Protected branches require approval before merge:

  • Only users with the editor or admin role can create merge requests targeting protected branches.

  • A minimum number of approvals may be required (configurable per group).

Import / Export

Ontologies can be imported and exported in the following formats:

Format Extensions Use Case

Turtle

.ttl

Compact, human-readable RDF serialization

RDF/XML

.rdf

Standard RDF XML format

OWL

.owl

Web Ontology Language format

Export an ontology:

  1. Open the ontology.

  2. Click Export in the toolbar.

  3. Choose the format.

  4. The file downloads to your machine.
