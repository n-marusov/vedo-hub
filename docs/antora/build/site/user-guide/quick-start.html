Accessing the Platform

Once the VEDO Core stack is running (see the Developer Guide — Getting Started for setup), open the frontend in your browser:

http://localhost:3000

Logging In

Authentication is handled via Keycloak. After navigating to the frontend, you will be redirected to the login page.

Supported identity providers:

  • ESIA / Gosuslugi

  • Yandex

  • VK

  • Google

Creating Groups

Groups organize your projects into teams, departments, or domains. Groups can be nested (subgroups) up to 5 levels deep.

To create a group:

  1. Navigate to Groups from the sidebar.

  2. Click New group — you will be taken to the create group page (/dashboard/groups/new).

  3. Enter a Group name (required) — a URL-friendly slug is auto-generated from the name.

  4. Choose a Visibility level:

    • Private — only members can view the group and its projects.

    • Internal — any authenticated user (except external) can view.

    • Public — anyone can view without authentication.

  5. Click Create group.

After creation:

  • A success Toast notification appears at the bottom-right.

  • You are redirected to the group detail page (/dashboard/groups/:id).

Creating Subgroups

To create a group inside another group (subgroup):

  1. Navigate to the parent group page.

  2. Click New group (or navigate to /dashboard/groups/new?parent_id=<uuid>).

  3. The visibility is inherited from the parent group (read-only on the create page).

  4. A subgroup cannot be more visible than its parent (e.g., a Public subgroup under a Private parent is rejected).

Creating Your First Ontology

  1. Click New Ontology on the dashboard.

  2. Enter a name and description.

  3. Click Create — you will be taken to the ontology editor.

Importing an Existing Ontology

VEDO Core supports importing from the following formats:

  • Turtle (.ttl)

  • RDF/XML (.rdf, .owl)

  • OWL (.owl)

To import:

  1. Open the ontology list.

  2. Click Import.

  3. Select the file and format.

  4. Click Upload.
