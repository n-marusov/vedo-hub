Overview

The iterative refinement feature lets you improve AI-generated ontology structures through natural language feedback. Instead of starting over, you can provide specific instructions to modify the existing structure.

How Refinement Works

  1. Generate an initial ontology (via document extraction, NL→OWL, or template)

  2. Review the proposed sequence of ontology operations

  3. Provide natural language feedback (e.g., "Merge Employee and Customer into Person with roles")

  4. The LLM generates a refined sequence incorporating your feedback

  5. Multiple rounds of refinement can be applied sequentially

Refinement Examples

Before refinement
Classes: Person, Employee, Customer, Vendor
Feedback
Merge Employee and Customer into Person with a "type" property.
Add Organization class and relate Person via "memberOf".
After refinement
Classes: Person (with type property: employee, customer, vendor)
         Organization
Object property: memberOf (Person → Organization)

Tips

  • Be specific about what to add, modify, or remove

  • Reference existing class and property names in your feedback

  • Use multiple rounds for complex refinements — each round builds on the previous

  • Review the changes before applying to ensure they match your intent

  • If the result is unsatisfactory, provide more detailed feedback in the next round
