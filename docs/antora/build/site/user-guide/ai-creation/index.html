Overview

VEDO Core provides AI-assisted ontology creation tools that help you build knowledge graphs faster and more efficiently. These tools include:

  • Document Extraction — Extract ontology structures from documents (MD, TXT, PDF, DOCX, JSON, XML, CSV, XLSX)

  • NL→OWL Generation — Convert natural language descriptions into OWL ontology axioms

  • Batch Upload — Upload and process multiple documents at once

  • Iterative Refinement — Refine generated ontologies with natural language feedback

Prerequisites

To use AI-assisted features, you need:

  • An LLM provider configured (OpenAI-compatible API, Anthropic, or local Ollama)

  • For document extraction: documents in supported formats

  • For NL→OWL: clear natural language descriptions of your ontology requirements

Getting Started

  1. Navigate to the AI Creation section in the left sidebar

  2. Choose one of the available features:

    • Upload Document — to extract from an existing document

    • NL to OWL — to generate from natural language

  3. Follow the on-screen instructions for each feature

Configuration

AI features require LLM provider configuration. See the Document Extractor Service Architecture and the LLM Provider Configuration for details.
