Overview

The document extraction feature allows you to upload documents and automatically extract ontology structures (classes, properties, relationships) using an LLM. Supported formats include:

  • Text documents: Markdown (.md), Plain Text (.txt), PDF (.pdf), Word (.docx)

  • Structured data: JSON (.json), XML (.xml), CSV (.csv), Excel (.xlsx)

How It Works

  1. Upload a document using the upload interface

  2. The Document Extractor service parses the document content

  3. The parsed content is sent to the configured LLM provider for ontology extraction

  4. The extracted structure is presented as a preview sequence of ontology operations

  5. You can review, edit, and apply the sequence to your ontology

Step-by-Step Guide

  1. Click Upload Document in the AI Creation section

  2. Select a document file (max 20 MB)

  3. Wait for the extraction to complete

  4. Review the generated sequence in the preview table

  5. Edit labels or toggle step inclusion as needed

  6. Click Apply to commit the changes to your ontology

Limitations

  • Maximum file size: 20 MB (synchronous), larger files trigger async processing

  • Scanned PDFs (image-only) cannot be extracted — OCR is not yet supported

  • CSV files must have a header row for property detection

  • Excel files use the first sheet by default
