= LLM Provider Configuration
:description: Configure LLM providers for AI-assisted ontology features.

== Overview

VEDO Core supports multiple LLM providers for AI-assisted ontology creation. The LLM provider is configured via environment variables, shared across the API Gateway and Document Extractor service.

== Supported Providers

|===
| Provider | `LLM_PROVIDER` value | API Format
| OpenAI | `openai` | OpenAI-compatible REST API
| Anthropic | `anthropic` | Anthropic Messages API
| Ollama (local) | `ollama` | OpenAI-compatible (Ollama proxy)
| Generic compatible | `openai` with `LLM_BASE_URL` | OpenAI-compatible REST API
|===

== Global Configuration

|===
| Variable | Default | Description
| `LLM_PROVIDER` | `openai` | Provider name
| `LLM_API_KEY` | — | API key for the provider
| `LLM_MODEL` | `gpt-4o` | Model identifier
| `LLM_BASE_URL` | — | Base URL (for compatible APIs)
| `LLM_TIMEOUT` | `30s` | Request timeout
| `LLM_MAX_TOKENS` | `4096` | Maximum response tokens
| `LLM_TEMPERATURE` | `0.7` | Generation temperature (0.0–2.0)
|===

== Provider-Specific Overrides

Override specific parameters per provider using the `LLM_PROVIDERS_<NAME>_<KEY>` pattern:

....
LLM_PROVIDERS_OPENAI_API_KEY=sk-...
LLM_PROVIDERS_OPENAI_MODEL=gpt-4o

LLM_PROVIDERS_ANTHROPIC_API_KEY=sk-ant-...
LLM_PROVIDERS_ANTHROPIC_MODEL=claude-3-opus-20240229

LLM_PROVIDERS_OLLAMA_BASE_URL=http://localhost:11434/v1
LLM_PROVIDERS_OLLAMA_MODEL=llama3
....

== Local Development with Ollama

For development without external API calls:

. Start the Ollama container:
+
....
docker compose -f docker-compose.yml -f docker-compose.llm.yaml --profile llm up -d
....

. Pull a model:
+
....
docker exec -it vedo-core-ollama-1 ollama pull llama3
....

. Set environment variables:
+
....
export LLM_PROVIDER=ollama
export LLM_PROVIDERS_OLLAMA_BASE_URL=http://ollama:11434/v1
export LLM_PROVIDERS_OLLAMA_MODEL=llama3
....
