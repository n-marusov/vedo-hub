= Getting Started
:description: Prerequisites, build, and local development environment for VEDO Core.

== Prerequisites

|===
|Tool |Version |Required for

|Docker |24+ |All services (containers)
|Docker Compose |v2+ |Full-stack orchestration
|Make |any |Build orchestrator (`src/Makefile`)
|Go |1.21+ |Go services, `vedo-cli`
|Rust |1.75+ |Rust services (ontology, versioning, publisher)
|Python |3.11+ |Python services (metrics, classifier)
|Node.js |20+ |Frontend services
|pnpm |8+ |Frontend package manager
|===

[NOTE]
====
If you just want to run the stack, Docker + Make is enough — language toolchains are only needed for local development and building from source.
====

== Quick Start with Docker

[source,bash]
----
git clone --recurse-submodules <repo-url> vedo-hub
cd vedo-hub

# Start all services + databases + Keycloak
cd src && make docker-up
----

The full stack includes 28 containers (14 application services, 4 databases, Keycloak, and build steps). Health checks are configured on every service; `make docker-up` returns once all are healthy.

=== Verify the Stack

[source,bash]
----
# API Gateway health
curl http://localhost:8080/health
# {"status":"healthy"}

# Frontend
curl http://localhost:3000/

# Neo4j Browser — http://localhost:7474 (neo4j / password)
----

== Default Ports

|===
|Service |Port

|Frontend |3000
|API Gateway |8080
|Ontology Service (Rust) |8081
|Versioning Service (Rust) |8082
|Auth Service (Go) |8084
|Metrics Service (Python) |8086
|Neo4j (Bolt / Browser) |7687 / 7474
|PostgreSQL |5432
|Redis |6379
|RabbitMQ (AMQP / Management) |5672 / 15672
|Keycloak (UI) |8180
|===

Keycloak default admin credentials: `admin` / `admin`.

== Running Individual Services

=== Frontend

[source,bash]
----
cd src && make dev-frontend
# Starts Vite dev server with hot-module replacement on :3000
----

=== API Gateway

[source,bash]
----
cd src && make dev-api
# Starts Go API Gateway on :8080
----

=== Rust Services

[source,bash]
----
cd src/services/ontology-service && cargo run
----

See xref:architecture.adoc[Architecture] for all services and their entry points.

== Building from Source

[source,bash]
----
# Build all services (Rust, Go, Python, TypeScript)
cd src && make build

# Build only Docker images
cd src && make docker-build

# Lint everything
cd src && make lint

# Run all tests
cd src && make test

# Full CI check (build + lint + test + typecheck)
cd src && make ci
----
