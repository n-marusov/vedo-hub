= Testing
:description: Test suites, how to run them, and what they cover.

== Test Suites

Cross-service test suites are in `tests/`:

|===
|Suite |Path |Description

|E2E |`tests/e2e/playwright/` |Playwright end-to-end browser tests
|Security |`tests/security/` |BOLA/BFLA authorization tests
|CLI |`tests/cli/` |vedo-cli integration tests
|Ticket API |`tests/ticket-api/` |Ticket API contract tests
|===

== Running Tests

=== Unit Tests (Fast)

[source,bash]
----
cd src && make test
----

Runs unit tests for all languages without external infrastructure:

* **Rust:** `cargo test --lib` (unit tests only — no PostgreSQL/Neo4j needed)
* **Go:** `go test ./...`
* **Python:** `uv run pytest`
* **TypeScript:** `pnpm test`

This is the standard feedback loop during development — no databases required.

=== All Tests (Including Integration)

[source,bash]
----
cd src && make test-all
----

Runs the full test suite including Rust integration tests that require
PostgreSQL and Neo4j. Set these environment variables first:

[source,bash]
----
export PG_TEST_DATABASE_URL=postgres://postgres:password@localhost:5432/vedo_test
export NEO4J_TEST_URI=bolt://localhost:7687
export NEO4J_USER=neo4j
export NEO4J_PASSWORD=password
cd src && make test-all
----

Integration tests gracefully skip with a clear message to stderr when
the relevant environment variable is unset.

=== Coverage

[source,bash]
----
cd src && make coverage
----

Runs Go tests with coverage profiles (`cover.out` per service).

=== Individual Languages

[source,bash]
----
# Rust — unit tests only
cd src/services/ontology-service && cargo test --lib

# Rust — all tests (including integration, requires DB)
cd src/services/versioning-service && cargo test

# Go
cd src/services/api-gateway && go test ./...

# Python
cd src/services/metrics-service && uv run pytest

# TypeScript
cd src/services/frontend && pnpm test
----

== Security Tests

Security tests in `tests/security/` verify:

* *BOLA* (Broken Object-Level Authorization) — users cannot access other users' ontologies, groups, or merge requests.
* *BFLA* (Broken Function-Level Authorization) — users cannot invoke admin-level operations without proper roles.

Run security tests:

[source,bash]
----
cd tests/security && go test -v ./...
----

== E2E Tests

End-to-end tests use Playwright to simulate user interactions through the browser:

[source,bash]
----
cd tests/e2e/playwright && npx playwright test
----

Requires the full stack running (`make docker-up` from `src/`).
