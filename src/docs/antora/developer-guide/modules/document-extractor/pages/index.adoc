= Document Extractor Service
:description: Architecture and design of the Document Extractor microservice.

== Overview

The Document Extractor service is a Python microservice that provides AI-assisted ontology extraction from documents. It parses documents in various formats, sends them to an LLM for ontology extraction, and applies the resulting sequence to the ontology service via gRPC.

== Architecture

[cols="2,2,3"]
|===
| Component | Technology | Responsibility
| API Layer | FastAPI | HTTP endpoints for upload, extraction, health checks
| File Parsers | Python | Parse MD, TXT, PDF, DOCX, JSON, XML, CSV, XLSX
| LLM Client | httpx | Communication with configured LLM provider
| gRPC Client | grpcio | ApplySequence RPC to ontology-service
| Sequence Validator | Python | Validate and sanitize LLM-generated sequences
|===

== Endpoints

|===
| Endpoint | Method | Description
| `/health` | GET | Health check
| `/ready` | GET | Readiness check
| `/metrics` | GET | Prometheus metrics
| `/api/v1/upload` | POST | Upload document for extraction
| `/api/v1/convert` | POST | NL→OWL conversion
|===

== gRPC Integration

The service connects to the ontology-service via gRPC for the `ApplySequence` RPC:

* **Target:** `ontology-service:9001`
* **Service:** `OntologyService`
* **RPC:** `ApplySequence`
* **Transport:** gRPC (with optional TLS)
