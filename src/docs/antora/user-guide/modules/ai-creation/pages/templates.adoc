= Ontology Domain Templates
:description: Start your ontology from pre-built domain templates.

== Overview

Domain templates provide pre-defined ontology structures for common domains. Instead of starting from scratch, you can select a template and customize it to your needs.

== Available Templates

|===
| Template | Classes | Properties | Description
| Person | Person | name, email, phone, address | Basic person/contact ontology
| Organization | Organization, Department, Team | name, industry, foundedDate, parent | Organizational structure
| Product | Product, Category, SKU | name, price, description, category | Product catalog ontology
| Research | Paper, Author, Journal, Conference | title, year, author, citation | Academic research ontology
|===

== How to Use

. Navigate to **AI Creation → Use Template**
. Browse the available templates
. Select a template to see a preview of the classes and properties it includes
. Click **Apply** to add the template's entities to your ontology
. Customize the generated classes, properties, and relationships as needed

== Customizing Templates

After applying a template, you can:

* Add new classes and properties
* Modify existing property domains and ranges
* Add object properties to create relationships between template classes
* Delete entities that are not relevant to your use case
