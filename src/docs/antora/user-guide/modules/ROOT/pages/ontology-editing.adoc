= Ontology Editing
:description: Working with classes, properties, and relationships in the VEDO Core editor.

== Ontology Editor

The ontology editor provides a visual graph interface powered by Vue Flow. It supports:

* Drag-and-drop node creation and positioning
* Class and property editing panels
* Relationship drawing between classes
* Real-time collaboration with other users

== Classes

=== Creating a Class

. Right-click on the canvas and select *Add Class*.
. Enter a class name (IRI label).
. Optionally add a description.
. The class node appears on the canvas.

=== Editing a Class

. Click on a class node to open the properties panel.
. Edit the label, description, or annotations.
. Changes are saved to the current working branch.

== Properties

|===
|Property Type |Description

|Data property |Links a class to a literal value (string, integer, boolean)
|Object property |Links a class to another class (relationship)
|Annotation property |Metadata about a class or property (label, comment, version)
|===

To add a property:

. Select a class node.
. In the properties panel, click *Add Property*.
. Choose the property type.
. Enter the property name and range.

== Relationships

Relationships (object properties) are drawn as edges between class nodes:

. Hover over a class node — connection handles appear.
. Drag from the handle to another class node.
. Enter the relationship name.
. The edge is created and visible on the canvas.

== Real-time Collaboration

Multiple users can edit the same ontology simultaneously:

* *Node locking* — when a user is editing a node, it is visually locked for others.
* *Comments* — attach comments to any node for discussion.
* *Presence* — see who is currently viewing the ontology.

Collaboration events are communicated via WebSocket through the API Gateway.

== Performance

The editor is designed to handle ontologies with up to 1 million axioms:

* p95 response time < 1 second for navigation operations
* Incremental rendering — only visible nodes are rendered
* Efficient diff updates via GraphQL subscriptions

== Fork Demo Projects

Instead of creating an ontology from scratch, you can fork one of the 5 demo projects in the `VEDO Demos` group:

. Navigate to the *Projects* page.
. Click *Fork demo project*.
. Browse the available demo projects (Organization, Product, Process, Glossary, Event).
. Click *Fork* on the project you want to use as a starting point.
. A new private project is created in your personal workspace with a copy of the ontology.

You can also fork any public or internal project by visiting the project page and clicking the *Fork* button.
