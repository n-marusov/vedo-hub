= Quick Start
:description: How to access VEDO Core and start working with ontologies.

== Accessing the Platform

Once the VEDO Core stack is running (see the link:../../developer-guide/modules/ROOT/pages/getting-started.adoc[Developer Guide — Getting Started] for setup), open the frontend in your browser:

[source]
----
http://localhost:3000
----

== Logging In

Authentication is handled via Keycloak. After navigating to the frontend, you will be redirected to the login page.

Supported identity providers:

* ESIA / Gosuslugi
* Yandex
* VK
* Google

== Creating Your First Ontology

. Click *New Ontology* on the dashboard.
. Enter a name and description.
. Click *Create* — you will be taken to the ontology editor.

== Importing an Existing Ontology

VEDO Core supports importing from the following formats:

* Turtle (`.ttl`)
* RDF/XML (`.rdf`, `.owl`)
* OWL (`.owl`)

To import:

. Open the ontology list.
. Click *Import*.
. Select the file and format.
. Click *Upload*.
