# Unused variable errors in Vue components (OntologyWorkspace + MergeRequests)

**Date:** 2026-07-14 10:31
**Files:** src/services/frontend/src/pages/OntologyWorkspace.vue, src/services/frontend/src/components/organisms/MergeRequests.vue
**Severity:** low

## Problem

`vue-tsc --noEmit` reported 13 `TS6133` errors: unused variables in 2 Vue files.

Errors in `OntologyWorkspace.vue` (11):
- 8 unused icon imports (`Columns3`, `Pencil`, `Plus`, `Share2`, `Table2`, `Trash2`, `User`, `Workflow`)
- 2 unused destructured query loading vars (`treeLoading`, `individualsLoading`)
- 1 unused function (`selectIndividual`)

Errors in `MergeRequests.vue` (2):
- Unused `i` index parameter in two `v-for` loops

## Root Cause

**OntologyWorkspace.vue** — Task 8.1 (M1 Frontend Wiring) rewrote the template from mock data to Apollo real backend but forgot to remove the old icon imports and unused hooks. The icons were used in the mock template but not in the new template.

**MergeRequests.vue** — Pre-existing issue: `v-for="(section, i)"` declares `i` but never uses the index.

Both are caused by `noUnusedLocals: true` in `tsconfig.json` combined with Vue's `vue-tsc` type checker, which catches unused variables that Vite/Vue's build process normally ignores.

## Solution

**OntologyWorkspace.vue:**
- Removed 8 unused icon imports from the `lucide-vue-next` import statement
- Removed `loading: treeLoading` from the `CLASS_TREE_QUERY` useQuery destructuring
- Removed `loading: individualsLoading` from the `LIST_INDIVIDUALS_QUERY` useQuery destructuring  
- Removed the dead `selectIndividual()` function (was never called from template)

**MergeRequests.vue:**
- Changed `v-for="(section, i) in sections"` → `v-for="section in sections"` (twice)

## Prevention

- Run `vue-tsc --noEmit` as part of CI to catch unused variables before merge
- Add `"typecheck": "vue-tsc --noEmit"` to frontend CI step (already exists in package.json)
- When rewriting Vue templates, always verify that all imports and script setup variables are still used in the new template
