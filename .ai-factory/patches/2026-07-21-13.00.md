# Apollo mock resolvers missing for CreateIndividual/CreateProperty/CreateClass mutations

**Date:** 2026-07-21 13:00
**Files:**
- `src/services/frontend/src/__tests__/setup/mock-providers.ts`
- `src/services/frontend/src/__tests__/CreateIndividualDialog.spec.ts`
- `src/services/frontend/src/__tests__/VersioningTabs.spec.ts`
- `src/services/publish-browse-ui/package.json`
- `src/services/publish-browse-ui/pnpm-workspace.yaml`
- `src/services/publish-browse-ui/.npmrc`
**Severity:** medium

## Problem

`make test-typescript` failed with:
1. 5 test failures in frontend (CreateIndividualDialog, CreatePropertyDialog, VersioningTabs)
2. pnpm install failure in publish-browse-ui due to `ERR_PNPM_IGNORED_BUILDS`

## Root Cause

**Test failures:** The Apollo mock link had no resolvers for `CreateIndividual`, `CreateProperty`, and `CreateClass` mutations, so mutations returned `{ data: {} }` and `result?.data?.createIndividual` was undefined — the `emit("created")` was never called.

Additionally, the CreateIndividualDialog test only set the name field but not the class selector, so form validation (checking `selectedClass`) returned early before the mutation was even called.

The VersioningTabs tests expected "Repository Graph" and "Compare Revisions" but these are page **titles** (shown only when those views are active), not tab labels. Tab labels are just "Graph" and "Compare".

**publish-browse-ui install failure:** pnpm v11 introduced a new `ERR_PNPM_IGNORED_BUILDS` validation. The `.npmrc` had `ignoredBuiltDependencies=@biomejs/biome,esbuild` which is now a hard error. The `pnpm-workspace.yaml` had auto-generated `allowBuilds` entries with placeholder text (`set this to true or false`) instead of `true`.

## Solution

**Test fixes:**
- Added mock resolvers for `CreateIndividual`, `CreateProperty`, and `CreateClass` in `mock-providers.ts`
- Added `classSelect.setValue("owl:Thing")` in CreateIndividualDialog test to pass validation
- Fixed VersioningTabs expectations: "Repository Graph" → "Graph", "Compare Revisions" → "Compare"

**publish-browse-ui fixes:**
- Replaced `ignoredBuiltDependencies` in `.npmrc` with `onlyBuiltDependencies[]` (pnpm v11 format)
- Set `allowBuilds: true` for `@biomejs/biome` and `esbuild` in `pnpm-workspace.yaml`
- Added `test` script (`echo 'No tests configured'`) to `package.json`

## Prevention

- When adding new dialog components with Apollo mutations, always add a mock resolver in `mock-providers.ts` to the `VITEST_MOCK_RESOLVERS` map
- Test expectations should match actual component template text (not inferred/speculative text)
- Dialog form tests must satisfy ALL validation checks (required fields) before testing submit behavior
- When upgrading pnpm major versions, check for new build policy validations like `ERR_PNPM_IGNORED_BUILDS`
