## Problem

10 TypeScript typecheck errors across 9 files in the Vue 3 frontend. Errors were:
- Unused imports/variables (4 errors)
- Type mismatch in Vue Test Utils plugins cast (1 error)
- `refetch()` type inference incompatibility with `@click` handler (3 errors)
- Undefined property access (`c.createdAt`) without null check (1 error)
- Ambiguous string indexing on `unknown` type (1 error)

## Root Cause

Three root causes:
1. **Unused imports/variables** — Lint/dead-code cleanup was not run after refactoring. `onUnmounted`, `UserCheck`, and `mergedCount` became unused when the code they supported was moved or removed.
2. **`useQuery().refetch` type inference** — The `refetch` function returned by `@vue/apollo-composable` correctly infers its variable types from the query. When used directly as a `@click` handler, Vue Template Compiler sees a mismatched signature (refetch expects query variables, `@click` expects `PointerEvent`). Wrapping with `() => refetch()` avoids the type conflict.
3. **`Record<string, unknown>` indexing** — When mapping API results typed as `Record<string, unknown>`, accessing `p.name[0]` on an `unknown` field requires an explicit cast before indexing.

## Solution

Applied 10 focused fixes:

1. `mock-providers.ts:167` — Cast `userPlugins` as `any[]` for spread compatibility
2. `App.vue:133` — Removed unused `onUnmounted` from import
3. `MergeRequests.vue:65` — Removed unused `mergedCount` computed
4. `CommentsPage.vue:69` — Added `?? ""` fallback for optional `c.createdAt`
5. `DashboardPage.vue:143` — Removed unused `UserCheck` from import
6. `GroupsPage.vue:44` — `@click="() => refetch()"` wrapper for type-safe handler
7. `MembersPage.vue:20` — `@click="() => refetch()"` wrapper
8. `ProjectsPage.vue:56` — `@click="() => refetch()"` wrapper
9. `ProjectsPage.vue:220` — Cast `p.name as string` before indexing `[0]`
10. `ValidationPage.vue:36` — Cast `violations` to typed array for `ValidationReport` prop

## Prevention

- After any refactoring that removes or renames component dependencies, run `vue-tsc --noEmit` to catch unused imports
- When binding `useQuery().refetch` to DOM event handlers, always wrap with `() => refetch()` to avoid parameter type mismatches
- When using `Record<string, unknown>` for API response typing, cast before accessing nested properties or indexing
