# test-quality-gate blocks ci-full on tautology assertions and .venv false positives

**Date:** 2026-07-26 22:10
**Files:** tools/scripts/test-quality-gate.sh, apps/services/frontend/src/__tests__/p0_ui_graph_search.spec.ts, apps/services/frontend/src/__tests__/p0_ui_import_export.spec.ts, apps/services/frontend/src/__tests__/p0_ui_suggestions.spec.ts, apps/services/frontend/src/__tests__/p0_ui_system.spec.ts
**Severity:** medium

## Problem

`make ci-full` failed at the `test-quality-gate` step with 68 B1 (tautology assertion) block violations — all `expect(true).toBe(true)` in 4 placeholder test files (`p0_ui_*.spec.ts`). Additionally, B2 (sleep), B4 (process exit), and B6 (inline tests) found false positives in `.venv/`, `vendor/`, and `node_modules/` directories.

## Root Cause

Two separate issues:

1. **Placeholder test files**: 4 `p0_ui_*.spec.ts` files contained `expect(true).toBe(true)` as intentional placeholder assertions inside `describe.skip` blocks. The quality gate script did not distinguish between active and skipped tests, flagging all tautology assertions regardless.

2. **No vendor/external directory exclusion**: The quality gate script (`test-quality-gate.sh`) ran `grep` and `find` across the entire `apps/services/` tree without excluding `.venv/`, `vendor/`, or `node_modules/` directories. This caused false positives from third-party packages (setuptools, rich, pydantic, golang vendored libs, npm packages).

## Solution

1. **Fixed placeholder tests**: Replaced `expect(true).toBe(true)` with `// TODO: implement when UI component is built` comments and removed the unused `expect` import. Since these tests are inside `describe.skip`, they are never executed, so an empty body is semantically correct.

2. **Added directory exclusions to the quality gate script**:
   - Added `--exclude-dir=.venv` to all `grep` commands (B1, B2, B4, B6_Python)
   - Added `--exclude-dir=vendor` and `--exclude-dir=node_modules` to B6 (Go, TS, Python)
   - Added `--exclude-dir=__tests__` to B6_TS to avoid flagging test helper files
   - Refined B6_TS grep patterns from `'it('` / `'test('` to `'^\s*it('` / `'^\s*test('` with word boundaries to avoid matching method calls like `.split('` or `.test(value)`
   - Added `-name '.venv' -prune` to the B7 `find` command to skip virtualenv directories

## Prevention

- When creating placeholder skipped test files, use comments instead of tautology assertions
- When adding new anti-pattern checks to the quality gate, always add `--exclude-dir` for `.venv`, `vendor`, `node_modules`
- When using `grep` patterns against source code, prefer `^\s*` prefix or `\b` word boundaries to avoid matching method/function call substrings
- Run `bash tools/scripts/test-quality-gate.sh apps/services` locally before committing changes that add new test files
