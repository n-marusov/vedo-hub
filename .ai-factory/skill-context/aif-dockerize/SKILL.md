## Rules

### Internal Services Use `expose`, Not `ports`

**Source**: `2026-07-24-12.00.md` (11 internal services published on host)
**Rule**: In `deploy/docker-compose.yml`, internal services (versioning, auth, metrics, publisher, public-browse-api, commenting, ticket-*, document-extractor) use `expose` (bridge-network only) — NOT `ports` — per ADR-IMPL.STACK.port-mapping-strategy. Public services (frontend, api-gateway, publish-browse-ui, neo4j, postgres, redis, rabbitmq, minio, keycloak) use `ports`. A new internal service with `ports` requires justification in the ADR. Use precise env var names: `SERVICE_REST_PORT` + `SERVICE_CONTAINER_GRPC_PORT`, never simplified `SERVICE_PORT`.

### Runtime-Generated Files vs Static Pre-Compression

**Source**: `2026-08-01-21.56.md` (stale config.js.gz served by gzip_static)
**Rule**: Files regenerated at runtime (e.g. `config.js` written by `docker-entrypoint.sh`) must be excluded from static pre-compression (`gzip -9 -k` find with `! -name "config.js"`), or the entrypoint must `rm -f "${CONFIG_FILE}.gz"` after writing — `gzip_static on` silently serves the stale `.gz` to gzip-capable clients (every browser).

### Dockerfile Copies pnpm-workspace.yaml

**Source**: `2026-07-30-13.44.md` (ERR_PNPM_LOCKFILE_CONFIG_MISMATCH in image)
**Rule**: For TypeScript services using pnpm with `overrides` in `pnpm-workspace.yaml`, the Dockerfile (`Dockerfile.typescript`) must copy `pnpm-workspace.yaml` into the image alongside `package.json`/`pnpm-lock.yaml` — otherwise `pnpm install --frozen-lockfile` fails with `ERR_PNPM_LOCKFILE_CONFIG_MISMATCH`. Also ensure `allowBuilds` values are real booleans and `.npmrc` has matching `onlyBuiltDependencies[]` (biome, esbuild, lefthook, vue-demi).

### Python Services Require pyproject.toml + uv.lock

**Source**: `2026-07-27-23.32.md` (uv.lock: not found)
**Rule**: `Dockerfile.python` copies `pyproject.toml` and `uv.lock` from each service directory. Every Python service scaffold must include both files, even with empty `dependencies` (stdlib-only services). Run `uv lock` after creating `pyproject.toml` to generate the matching lockfile.
