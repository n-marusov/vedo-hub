### Placeholder/Skipped Tests Use Comments, Not Tautologies

**Source**: `2026-07-26-22.10.md` (68 B1 violations in describe.skip blocks)
**Rule**: Skipped/placeholder tests must use `// TODO: implement when ...` comments, NOT tautology assertions (`expect(true).toBe(true)`) — B1 (tautology) detection flags them even inside `describe.skip`. Empty bodies are semantically correct for never-executed skipped tests; remove unused `expect` imports.
