### JWT Test Infrastructure Integrity

**Source**: `2026-07-26-22.17.md` (33/64 E2E API tests failed with 401)
**Rule**: When test plans involve authenticated E2E API tests: (a) `tests/e2e/scripts/test-jwt-key.pem` is a committed test-only key — not a production secret, never gitignored; (b) JWT tokens must be regenerated with <24h expiry before each run (global-setup.ts does this); (c) trace `global-setup.ts` OUTPUT_PATH against the consumer's import path — it writes to `resolve(__dirname, '..', 'specs', 'jwt-tokens.ts')`, and specs/helpers import from `specs/jwt-tokens.ts`. A wrong OUTPUT_PATH makes regeneration invisible to consumers.

### i18n Test Strategy

**Rule**: i18n test plans must include: (a) key-parity checks between `ru.json` and `en.json` (identical key sets, both directions); (b) component tests that mount `App.vue` assert structure, not label text, so localization changes don't break them; (c) a shared test-setup locale preload (`vitest.setup.ts` → `setLocale("en")`) instead of per-test `setLocale` so components render real translated strings.
