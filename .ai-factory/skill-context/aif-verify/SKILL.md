### Test Quality Gate — Step 1 (Fail-Fast)

**Source**: `$aif-test-quality` skill, `.ai-factory/rules/test-quality.md`
**Rule**: `$aif-verify` MUST invoke `$aif-test-quality` as **Step 1** — before task completion audit (current Step 1), code quality checks (Step 2), and consistency checks (Step 3).

**Why:** Bad tests should block immediately. Running task audits and lint checks on code tested by broken tests wastes time and produces misleading "PASS" results.

**Implementation:**
1. Insert a new "Step 1: Test Quality Gate" before the existing Step 1 (Task Completion Audit).
2. Invoke `$aif-test-quality` on the changed files / target service:
   ```
   $aif-test-quality <service-or-path>
   ```
3. Capture the gate result (PASS / BLOCK / WARN) and TQS/RCS scores.
4. If BLOCK → emit failure report and **stop** (do not proceed to Step 2+).
5. If WARN → proceed but include warnings in the final report.
6. If PASS or N/A (no tests) → proceed normally.
7. Renumber existing Steps 1–5 to Steps 2–6.

**Report integration:** Add TQS and RCS as the first two rows in the verification summary table (Step 4).
