**Source**: `2026-07-20-00.00.md` (JWT key mismatch), `2026-07-19-18.30.md` (Go version mismatch)
**Rule**: When documenting deployment or test setup, include a table mapping which `docker-compose*.yml` file to use for each scenario:

| Scenario | Compose File | Key Difference |
|----------|-------------|----------------|
| Development | `deploy/docker-compose.yml` | Uses Keycloak JWKS for auth validation |
| E2E Testing | `deploy/docker-compose.test.yml` | Uses `JWT_DEV_PUBLIC_KEY_PEM` for self-signed test tokens |
