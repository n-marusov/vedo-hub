### Grep-Based Gates: Vendor Exclusions + Word Boundaries

**Source**: `2026-07-26-22.10.md` (68 false positives from .venv/node_modules)
**Rule**: When writing grep-based quality gates, add `--exclude-dir=.venv --exclude-dir=vendor --exclude-dir=node_modules` (and `--exclude-dir=__tests__` for TS B6 checks) to every `grep`/`find`; use `^\s*it(` / `^\s*test(` patterns with word boundaries instead of bare `it(`/`test(` to avoid matching method-call substrings like `.split('` or `.test(value)`.

### Go Integration Gates Include -tags=integration

**Rule**: Gate scripts running Go integration suites (`//go:build integration` test files, e.g. `tests/security/authorization/`) must pass `-tags=integration` in the `go test` invocation. `go test ./...` returning "no packages to test" is a non-zero exit — treat it as a signal of missing build tags, not a pass.
