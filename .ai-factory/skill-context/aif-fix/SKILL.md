### LLM Prompt Injection Defense Checklist

**Source**: `2026-07-18-18.23.md` — M2 AI Ontology Creation (dead code, Unicode bypass, missing length limits)
**Rule**: When fixing LLM-related code (AI handlers, prompt builders, LLM provider calls), verify:

1. All defined sanitization/validation functions (e.g., `SanitizeUserInput`, `SanitizeLLMInput`, `ValidateLLMOutput`) are wired into response paths — not dead code
2. Unicode normalization (NFC) is applied before pattern matching; zero-width characters are stripped
3. Input length limits are enforced for all user-supplied text (prompts, feedback, class IDs)
4. All user-supplied values interpolated into prompts are sanitized before reaching the LLM
5. `http.NewRequestWithContext()` is used for all outbound LLM calls with `io.LimitReader` on response body

### Failure Propagation Rule

**Source**: `2026-07-14-20.30.md` — M1 Review (push_state returned Ok(()) on transport failure, unwrap_or(0) swallowed DB errors)
**Rule**: Transport errors must propagate to callers. Never return `Ok(())` after a failed network/DB call. Never use `unwrap_or(default)` to silently swallow errors — it hides data integrity bugs. Check `.error_for_status()` on HTTP responses and propagate `Err` from transport failures.

### ARIA Role Override on Native Elements

**Source**: `2026-07-20-14.30.md` (LoginPage button roles caused axe-core violation)
**Rule**: Do not set explicit ARIA roles on native HTML elements that already carry implicit roles (e.g., `<button>` already has `role="button"`, `<h1>` already has `role="heading"`). When `role="listitem"` is placed on a `<button>`, it overrides the implicit button role — `getByRole('button')` in Playwright will not find it. Removing the parent container's `role="list"` avoids the axe-core `aria-required-children` violation entirely.

### Go Integration Test Build Tags

**Source**: `2026-07-19-21.29.md` (commenting-service integration tests failed without PostgreSQL)
**Rule**: When fixing integration tests in Go, verify the test file has `//go:build integration` constraint (both Go 1.17+ and legacy syntax). Use `t.Skipf()` instead of `t.Fatalf()` when external dependencies (PostgreSQL, Neo4j) are unreachable — this gracefully skips the test instead of failing. When using `t.Skip()` inside a helper that the caller uses to obtain resources, use `t.Cleanup()` inside the helper instead of `defer` in the caller, because `runtime.Goexit()` from `t.Skip()` runs the caller's deferred calls with zero-valued resources.
